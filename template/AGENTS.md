# 시장조사 프로젝트 규칙 (Claude Code · Codex 공통)

<조직> 의 조사 프로젝트 폴더. 조사 1건 = 하위 폴더 1개 `research_<주제>_<YYYYMMDD>/`.
증빙형 보고서는 `market-deep-research` 스킬, 검색만은 `mdr-search`, hwpx 양식화는 `mdr-hwpx`.
스킬이 안 보이면 설치부터: https://github.com/bbiyakfather/market-deep-research (README 「팀원 설치」).

## 절대 규칙 (스킬 3대 원칙의 프로젝트판)
- 원문에서 확인 못 한 수치는 쓰지 않는다. 출처 없는 주장은 사실대장(`audit/facts.jsonl`)에 못 들어가고, 대장에 없는 수치는 본문에 못 쓴다.
- 보고서 본문(`report.md`)의 수치를 직접 고치지 않는다. 대장을 고치고 다시 렌더한다.
- 고객용 산출물과 내부 `audit/` 를 섞지 않는다. 실패 URL·폐기 목록·검증 이력은 `audit/` 에만.

## 실행 위치
- 스킬 스크립트는 **반드시 조사 작업폴더(`research_*/`) 안에서** 절대경로로 실행한다. 스킬 폴더에서 돌리면 조사 원문이 스킬 소스에 섞인다.
- 대외비 조사는 `MDR_NO_THIRD_PARTY=1` 을 켠다(외부 열람 서비스 Jina·Wayback 차단).

## 문체·형식 (보고서 공통)
- 자료는 주체를 밝혀 인용한다("○○ 자료에 따르면"). "발표자료는~" 식 무주체 인용 금지.
- 수치 데이터는 그림이 기본, 표는 식별자·비교표·값 참조일 때만. 문장형 칸은 세로 묶음 표.
- 전년판이 있는 업데이트 보고서는 전년판을 먼저 읽고, 전년 결론을 올해 결론에서 하나씩 추적한다.

## 교훈 누적
- 조사 중 틀린 수치·절차 사고가 나면 `tasks/lessons.md` 에 「발생 / 원인 / 방지책」 3줄로 바로 적는다.
