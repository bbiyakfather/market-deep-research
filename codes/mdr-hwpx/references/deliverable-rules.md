# deliverable-rules — 증빙판(report.md) → 납품본 원고 변환 규칙

2026-10-02 이리듐 저감 조사 납품본 1차 수정에서 발주처가 지적한 것을 규칙으로 고정한다.
원고를 쓰기 **전에** 적용한다(사후 치환은 opus 전수 리뷰 130건·워커 6명분 비용이 들었다).

## 1. 작성 주체 표현
- "조사팀"을 쓰지 않는다. 보고서 작성 기관(내비온파트너스)이 주체이며, 기관명은 조사 개요에서 한 번만.
- 증빙판의 `(조사팀 판단)` → 납품본 라벨 `**(평가)**`·`**(종합)**`·`**(시사점)**`. 서술 속 "조사팀이 환산·확인" → 주어 없는 명사형("환산값", "확인됨"). 꼭 필요하면 "본 보고서".
- 작업 흔적 어휘(대장·캡처·태그·워커·재열람·G3·MCP 응답·검색 응답·수집분·수집 범위·모집단·옮기지 않음)는 본문 금지. 도구 출처는 공개 명칭으로("PatSnap 특허 DB 집계(2026년 9월 검색)").

## 2. 내부 코드·조어 금지
- 조사 단계 분류 코드(`T1~T7`, `Q1r~Q4r`, `표기 변형 A·B`, `TM`)는 납품본에서 전부 명칭으로 푼다. 제목·표 캡션·표 셀·그림 범례까지(그림은 라벨을 고쳐 재생성).
- 판정 조어는 일반어로: 갈래→기술 분류, 축→조사 항목, 묶음→세부 분류, 경로(성막)→방식, 격차 표→목표 대비 현황 표, 증빙 공백→근거가 없는 구간, 확정값→보고값, 산식→산정 방식, 순위 아님→조건이 달라 직접 비교 불가, 무게 이동→중점 이동, 청구 문턱값→청구항 로딩 상한값, 수리관청→출원 관청, 단기스택→쇼트 스택, 하프셀·반전지→반쪽전지. 라벨 `(…판단)`은 내용 라벨로.
- 약어는 **첫 등장**에 풀이하고 부록 용어 해설에 싣는다(PTE·PTL·CCM·MPL·HFR·iR 보정·ALD·PVD·AMR·MYPP·IPC·PCT·기관 약칭). 정의가 첫 등장보다 뒤에 있으면 결함. 한눈 요약이 본문보다 앞이면 요약에서 쓰는 약어는 요약 「읽는 법」에 "약칭은 Ⅱ장 표 1" 한 줄.
- 표기 통일을 원고 작성 전에 정한다(예: 산화극/음극으로 통일하되 정책 문서 인용 '산소극·수소극', 특허 청구 인용 '애노드'는 원문대로; 이오노머·Ir-free(이리듐 미사용)·직접 성막·루타일 한 가지).
- 검사: `grep -nE "\bT[0-9]\b|\bQ[0-9]r?\b|갈래|축별|묶음|격차 표|증빙 공백|확정값|산식|순위 아님|수리관청|조사팀" manuscript/*.md` → 0.

## 3. 불확실 정보 처리(발주처가 "확실하지 않은 것은 삭제"를 지시한 경우)
- 삭제: 학회·저널 **초록에만** 있는 값, 조건 없는 회사 주장("n배 절감", GW/t 환산), "같은 시편 여부 미확인"·"불명확"·"~로 보임"·"가능성"·"유보" 문장, 같은 원문 안 상충 값(둘 다 또는 본문 쪽만).
- 유지: 정부 목표·프로토콜 수치, 논문 본문 확인 값, 조건이 적힌 기업 수치("회사 보도자료 값" 한 마디), 통계 기관 공식 "잠정", 특허 청구 범위 값.
- **명단형 정보**(기관·경로·공개 형태)는 불확실 정보가 아니다. 수치 칸만 비우고('-') 명단 표로 남긴다. 수치 칸이 전부 비는 행은 수치 표에서 빼고 명단 표로.
- 속성 하나만 불확실하면(기관명 "(추정)") 그 속성만 뺀다(저자·연도 표기). 사실 자체를 지우지 않는다.
- 삭제 흔적("~는 조건 미확인으로 제외")을 본문에 남기지 않는다. 한계 서술은 시사점·한계 장 한 곳.
- 그림이 삭제한 값을 그대로 그리고 있으면 재생성(본문 확인 점만).

## 4. 분량·표
- **수치 데이터는 그림이 기본, 표는 예외.** 형식 결정은 MDR `references/visual-first.md`(결정표·표가 남는 경우), 모듈마다
  `python <MDR>/scripts/visual_audit.py manuscript/<모듈>.md --decisions audit/visual-decisions.json` 미결 0건. 아래 표 규칙은 '남는 표'에 적용.
- 분량 목표는 **바이트(`wc -c`)로 단위를 통일**해 지시한다(`wc -m` 과 섞이면 과삭제). 압축 순서: 불확실 정보 삭제 → 같은 결론 반복 제거(절 첫 문단 한 곳) → 방법 설명은 조사 개요 한 곳 → 불릿 3→2 → 표 열 축소.
- 표: 열 7개 이하, **셀 45자 이내**(긴 서술은 `* 출처 :` 줄 아래 `- 기관: 서술` 불릿, 표당 3개), '미기재'·'-'가 절반 넘는 열은 삭제, 근거 수준 열은 전 행이 같으면 삭제. 선도문(라벨 포함) 70자 이내.
- 캡션은 원고에 `<표> 표 n. 제목` 으로 쓰고 빌더가 `<표n> 제목` 으로 렌더한다(`<표> 표 1.` 중복 금지).
- 빌드는 `HWPX_TABLE_FLOAT_ALL=1` 로: 모든 표가 쪽 경계에서 행 단위로 나뉘어 빈 공간이 없다.

## 5. 참고문헌(부록)
- APA 7판. 학술 `성, 이니셜., … & 성, 이니셜. (연도). 제목. 학술지, 권(호), 면. https://doi.org/…`, 웹 `기관. (연도). 제목. URL`, 특허 `출원인. (연도). 제목 (공보번호). URL`, 학회 초록 `… [Conference abstract]. ECS Meeting Abstracts. URL`.
- DOI 가 있으면 DOI 만(원본 URL 생략), 같은 DOI 는 한 항목(학술 절 우선), 내부 도구 주소(MCP 엔드포인트)는 제품 홈페이지로.
- 유형별 절(정책·학술·기업·특허·시장통계·언론) 안에서 라틴 알파벳 → 한글 가나다. 각 항목은 `<sup>n)</sup> 항목` 각주형 문단(전체 일련번호). 번호·왼쪽 정렬·작은 글씨로 나온다. 단일 열 표는 가운데 정렬이라 쓰지 않는다. 평문 문단은 ❍ 가 붙는다.
- 생성: `python <this>/scripts/make_references.py --src <URL 목록 md> --out <부록.md> --evidence <evidence.jsonl> --snapshot-root <WD>`(Crossref·OpenAlex·스냅샷 메타, 수기 캐시). 외부 API 에는 DOI·URL 만 보낸다. Crossref 저자명은 본문 표기와 철자가 다를 수 있으니 표본 대조.

## 6. 윤문(korean-humanizer): 원고 완성·리뷰 반영 뒤 1회
- 장르 고정: `❍ **(라벨)** 선도문` + `- 근거` 불릿, 명사형 종결은 양식이므로 J-1·J-3 에 걸려도 유지. 표·그림·캡션·출처 줄·제목·경로 불변. 숫자·기관·연도 불변.
- 잡는 것: 번역투(A-1·A-2·A-3·A-7·A-8), 연결어미 뒤 쉼표(C-11), 결산 피벗·상투어(D), 문두 접속사(H-1), 같은 문장 틀 5개 연속("…리뷰는 …라고 적음"), 같은 라벨 3회+, 영어 병기 반복(B-1). 변경률 25% 이하.
- 개조식 원고는 변경률이 1~4% 에 그치는 게 정상이다(등급 A 조건의 10% 는 산문 기준).

## 7. 검증·리뷰 순서
1. 워커(sonnet) 모듈별 수정 → `BEFORE_DIR=<백업> python <this>/scripts/check_numbers.py <stem>`(새 숫자 EXTRA 0, 빠짐은 삭제분 목록) + 금지어 grep 0.
2. opus 전수 리뷰 1회: 모듈 간 정합(같은 사실 같은 값·같은 기관명), 삭제 후유증(표 번호·참조·근거 0개 라벨), 과삭제(본문 확인 사실 복원), 정본 대조 표본 30건, 임의 표현·약어·표기 혼용, 선도문·열·불릿 한도. 반영 후 윤문.
3. 빌드 → 최종 PDF 텍스트에서 금지어·코드·조어·대외비 수치·`<표> 표` 전수 grep → 0. 쪽수·목차 항목 수 확인.
- 단계마다 원고 백업 폴더(`_before_rev1/`, `_before_humanize/`, `_before_jargon/`)를 두고 검사 기준선으로 쓴다.
