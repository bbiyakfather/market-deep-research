# verification-gates — G0~G5 상세 · 4차원 등급 · confirmed 조건 · 환산옵션

SKILL.md 오케스트레이션 골격의 각 게이트를 실행 가능한 판정 기준으로 상세화한다. 게이트는 **통과/차단이 이분법**이다 — "대충 됐음"은 없다.

---

## 게이트 개요

| 게이트 | 입력 | 통과 조건 | 차단 시 처리 |
|---|---|---|---|
| G0 | 사용자 요청 | 의존성 OK + 요구사항 승인 (+기관조사면 entity_id 확정) | 누락 의존성 설치 안내 / 요구사항 재질의 |
| G1 | 조사원 JSONL | 스키마 검증 통과분 등재, 무출처 폐기 | 스키마 위반 라인 제한적 재요청 |
| G2 | 등재 fact | 전건 팀리드 재검증 + confirmed 전건 source_capture | 재검증 실패→pending 유지 / 캡처 불가→미확인 유지 |
| G3 | report.md + facts | verify_facts **실패 0** + manifest 해시 고정 | 실패 항목 수정 후 재실행 |
| G4 | report.pdf | 팀리드 육안검증 통과 | 렌더 문제 수정 후 G3 복귀 |
| G5 | 최종 PDF + manifest | F태그·링크·캡처 수 재검사 + 해시 재확인 | 변경 검출 시 G3 복귀 |

## G0 — preflight + 조사계획 확정
- **의존성 점검**: `python skill_paths.py --preflight`. 필수(python·fitz·curl_cffi·trafilatura·playwright·pandoc·chrome) 중 하나라도 absent면 **차단**(exit 1). yt_dlp는 선택(경고만).
- **요구사항 확정은 AskUserQuestion 도구로**: 조사유형·범위·**조사 종료 기준**·환산옵션(기본 OFF)·출력형식을 자유서술 질문이 아니라 **선택지 형태**(권장안 명시)로 묻는다. 모호함을 안고 팬아웃하면 조사원 토큰 전체가 헛돈다 — 게이트 중 가장 싼 지점에서 모호함을 제거하는 것이 G0의 존재 이유다.
- **목차 선제안 (하나의 보고서 계획)**: 팬아웃 전에 팀리드가 **보고서 목차 초안**을 만들어 사용자 승인을 받는다. 각 장마다 ① 핵심 질문 ② 필요한 수치(어떤 metric을 confirmed로 만들어야 하나) ③ 담당 조사원을 적는다. 이 목차가 조사원 분담([1])과 보고서 구조([3])의 **단일 기준**이 된다 — 목차 없이 팬아웃하면 조사 결과를 보고서에 꿰맞추게 되고, 목차가 있으면 조사가 보고서를 채우러 간다.
- **기준출처(anchor source) 합의**: 시장규모·설치용량처럼 **기관마다 수치가 갈리는 지표**는 어느 출처를 대표 기준으로 삼을지(예: 수소 분야면 IEA) 사용자와 합의해 목차에 적는다. 타 출처 수치는 폐기하지 않고 병기(disputed)하되, 본문 대표 서술은 기준출처를 따른다. 기준 없이 수집하면 [3]에서 "어느 수치로 쓸지"를 사후 결정하게 되어 상충 처리가 자의적으로 보인다.
- **기관/기업 조사면 entity-identity 게이트 선행**: `context.entity_id`(사업자등록번호 우선)를 확정한 뒤에만 조사원 팬아웃(entity-identity.md).

## G1 — join + 수집 게이트
- 전 에이전트 완료/timeout/부분실패를 처리하고, raw 산출물을 `_research/<agent>/`에 보존(무수정).
- `facts_db.py`로 **스키마 검증 후 등재** — 이때 팀리드가 임시 ID(TF/TE)를 정식 `F/E` ID로 채번한다. 원자적 append(부분쓰기·중복ID 방지).
- **출처 없는 주장은 즉시 `discarded`**(audit `discarded.md`에 사유 기록). 스키마 위반 라인은 해당 에이전트에 제한적 재요청.
- 등재 시 초기 status: 근거 있으나 미재검증 = `pending`. 상충 = `disputed`. 시계열 갱신 = `superseded`.

## G2 — 팀리드 재검증 + 증빙 게이트
- **★전건 재검증**: 보고서 진입 대상 모든 fact를 팀리드가 원문 재열람(WebFetch/fetch.py)하여 `verbatim`/`locator`를 대조하고 **verify_event를 기록**한다.
- **confirmed 조건 (엄격)**: `evidence ≥ 1` **AND** 팀리드 `verify_event{"action":"reread","result":"match"}`가 존재. 이 둘을 만족해야만 `status:"confirmed"`. 무출처는 confirmed 불가·본문 사용 불가.
- **verifier 단독 confirm 금지**: 검증 서브에이전트를 쓰더라도 그 의견은 보조일 뿐, confirm은 팀리드(lead)만 한다(`verified_by:"lead"`).
- **독립성 판정**: 같은 보도자료를 여러 매체가 전재한 경우 `source_role:"보도자료"`로 표기하고 **1출처로 합산**한다. 독립 출처 수를 부풀리지 않는다.
- **증빙**: confirmed 전건에 source_capture 생성(evidence-capture.md). 핵심 수치는 캡처 필수. 재구성 발췌(reconstructed_excerpt)는 **증빙 불인정** → 원본 캡처 불가 시 대체출처 or 미확인 유지.

## G3 — verify_facts + manifest (실패 0 필수)
`verify_facts.py`가 아래를 모두 통과해야 한다(하나라도 실패면 차단):

1. **본문/부록 분리 파싱** — 부록(근거표·요약표)의 F-ID는 "본문 사용"으로 계산하지 않는다(부록 우회 차단).
2. **무태그 탐지** — 본문의 숫자·통화·비율·날짜·표셀 중 `(Fxxx)` 없는 사실 주장을 차단.
3. **태그↔대장 존재+상태** — 모든 `(Fxxx)`가 대장에 존재하고 `status:"confirmed"`.
4. **의미 대조** — 태그가 가리키는 fact의 **값·단위·기간·주체**가 본문 서술과 일치(오태그 차단).
5. **유실 점검** — confirmed인데 본문 미사용 fact 목록 보고(누락 방지).
6. **필수필드** — evidence: `source_url`·`type`·`sha256`·`accessed_at`·`grade`(evidence.grade, 4차원 모두) 누락 0, `text_quote`는 `verbatim` 필수. fact: `grade`(fact.grade 대표등급, 4차원 모두) 누락 0.
7. **캡처 실재** — source_capture 경로 실재(핵심수치 필수). 파일명↔evidence ID 일치.
8. **manifest** — source/capture/report/PDF의 SHA-256 기록·이전과 대조. 변경 시 G3 재실행 트리거.
9. **[환산 ON일 때만]** §5 Decimal 검산 통과 + 본문 영어 통화 단어 0.

## G4 — 렌더 + 육안검증
- `render_pdf.py`로 오프라인 GitHub 스타일 PDF 생성 → `preview_pdf.py`(fitz 페이지 이미지)로 팀리드가 **육안 확인**(표·이미지·한글·캡처가 정상 렌더됐는지). 문제 시 원인 수정 후 G3 복귀.

## G5 — 최종 무결성
- 완성 PDF에서 **F태그 수·출처 링크·캡처 수**를 재검사하고 manifest 해시를 재확인. 파일이 변경됐으면 **G3로 복귀**.

## 오인방지 체크 (G2~G5 상시)

| 위험 | 무엇인가 | 어느 게이트가 잡나 |
|---|---|---|
| 무태그 | 본문 수치에 F-ID 없음 | G3-2 |
| 오태그 | F-ID는 있으나 값·기간·주체 불일치 | G3-4 (의미 대조) |
| 부록 우회 | 본문 대신 근거표에만 태그 달아 회피 | G3-1 (분리 파싱) |
| 캡처 교체 | 캡처 이미지를 다른 것으로 바꿔치기 | G3-8/G5 (manifest 해시) |
| 의미 불일치 | 캡처 속 값이 fact 값과 다름 | G2 (오귀속 육안) + G3-7 |

## 4. 4차원 등급 (A~D 판정 문장)

등급은 **두 층**으로 매긴다. 척도는 아래 4차원 A~D 판정 문장으로 공통이며, "종합 한 글자" 등급은 쓰지 않는다(팀리드가 G2에서 확정).
- **evidence.grade (필수)** — 출처(evidence) 하나하나에 대한 4차원 등급. 등급은 본질적으로 출처 속성이므로 여기가 1차이며, 모든 evidence가 가져야 한다.
- **fact.grade (대표등급)** — 그 fact의 대표 4차원 등급. **기본값 = 그 fact를 뒷받침하는 evidence 중 최고 권위(authority) evidence의 등급**이며, 팀리드가 필요 시 채택·조정한다(disputed면 대표를 보수적으로).

각 차원은 서로 **독립적으로** 매긴다.

### authority (출처 권위)
- **A** — 규제당국·감사보고서·법정 공시·표준제정기구·1차 통계기관 (예: DART 사업보고서, SEC 10-K, KOSIS, 감사받은 재무제표).
- **B** — 해당 기업/기관의 공식 발표(IR·보도자료·기술백서), 동료심사 논문.
- **C** — 신뢰도 있는 언론·업계 리서치(방법론 공개), 비심사 프리프린트.
- **D** — 익명·UGC·출처 불명(포럼·SNS·미검증 블로그). 단독 confirmed 근거로 쓰지 않는다.

### independence (독립성)
- **A** — 조사 대상과 **이해관계 없는 제3자**가 독립 취재/측정.
- **B** — 제3자이나 대상과 일부 관계(스폰서 리서치, 거래 파트너).
- **C** — 대상 **본인/자사** 발표(자기 보고).
- **D** — 대상이 배포한 홍보물의 재전재(같은 보도자료 다매체 = **합산 1출처**, source_role로 판정).

### directness (직접성)
- **A** — 값이 원문에 **직접 명시**되고 원본에 **직접 도달**(archived_url 없음).
- **B** — 원문 직접 명시이나 재구성 경로(Jina/Wayback, archived_url 있음)로 회수.
- **C** — 원문이 **재인용/요약**한 값(원 출처를 한 다리 건넘, source_role:"재인용").
- **D** — 값이 계산·해석을 거쳐야 나옴(원문에 그 숫자 자체는 없음). `calculation`은 입력이 A/B라도 이 차원은 보수적으로.

### recency (최신성)
- **A** — as_of 기준 최신 회계연도/분기, 또는 조사 목적상 "현재"로 유효한 시점.
- **B** — 1주기(1년/분기) 이전.
- **C** — 2~3주기 이전(추세 참고용).
- **D** — 그보다 오래됨 또는 시점 불명. 시점 불명은 본문 단정에 쓰지 않는다.

> 등급은 폐기 기준이 아니다. 저등급이라고 자동 폐기하지 않는다 — 상충은 `disputed`, 시계열 갱신은 `superseded`로 보존하고 등급으로 맥락을 표시한다.

## 5. 환산옵션 (기본 OFF)

기본값은 **환산하지 않음**. 원문 통화·단위를 그대로 쓴다. 사용자가 G0에서 ON으로 승인한 경우에만 아래를 지킨다:

- **Decimal 검산**: 부동소수점 금지. `decimal.Decimal`로 계산하고 식을 `calculation` evidence로 남긴다.
- **환율 출처·기준일 명시**: 어떤 환율을(출처) 언제(기준일) 적용했는지 evidence에 기록.
- **종가/평균 명시**: 기준일 **종가**인지 **기간 평균**인지 명시(둘은 다른 값).
- **본문 영어 통화 단어 0**: 환산 ON이면 본문에 영어 통화 표기(`million`, `USD` 서술 등)가 남지 않도록 통일(G3-9가 0을 확인). 표기 반올림 일관성 유지.
