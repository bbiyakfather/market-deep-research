# PRD — 시각화 우선(visual-first): "표 만능" 교정 (2026-10-08)

## 1. 배경·문제
- 사용자 지시(2026-10-08): "무조건 데이터를 표로 정리하는 게 아니라, 시각화가 가능한 자료면 시각화를 우선."
- 실측: 촉매 저감 문헌조사 v3 — 7열 표 3개·40행 깨알 차트·본문 표 23 vs 그림 10, 사용자 메모 P6 "시각자료 우선·표 슬림".
  체외진단 사업화 용역 v15 — 표 24·그림 1 → 사용자 메모 20건 반영 뒤 v17 표 16·그림 7. PEM 2026 폐기 초안 리뷰 26건 중 9건이
  이미지·인포그래픽 요구(#4·#6·#9·#10·#15·#18·#19·#26). 같은 리뷰의 #2·#3·#17 "표로 정리"는 **산문 나열**을 표로
  바꾸라는 것 — 수치 데이터를 표로 두라는 뜻이 아니다.
- 근본 원인: ① 증빙 체계가 셀 단위 F태그 결박에 최적화돼 표가 G3 통과에 가장 쉽다 ② `image-research.md` 가 자작 차트를
  "최후 수단(0~3 소진 뒤)"으로 규정 ③ 작성자(sonnet)가 분량·속도 압박에서 표로 도피 ④ 그림 vs 표 결정 규칙이 문서
  어디에도 없음 — 출처 순서(원문 도판 → 캡처 → 자작)와 형식 결정(그림 vs 표)이 한 줄에 섞여 있었다.

## 2. 목표 / 비목표
- 목표: (G1) 수치 데이터의 기본 표현을 그림으로 바꾸고 표를 예외 조건으로 둔다 (G2) 결정을 기계로 보조해 리드가 표마다
  판정을 남긴다 (G3) 증빙 결박(F태그·출처·confirmed 값만)은 약화하지 않는다.
- 비목표: 차트 스타일 가이드 신설(`dataviz` 스킬이 담당) · `make_chart.py` 유형 확장(후속) · 증빙판 3부 근거표 폐지
  (검증 구조라 유지, 납품 원고에서만 제외) · 표를 전부 없애기.

## 4. 수용 기준
- `python scripts/visual_audit.py --selftest` 통과. 실제 report.md 1건에서 후보 전건이 `keep`+사유 또는 표 삭제(그림 전환)로
  닫히면 종료코드 0 — `chart` 라고 적어 두기만 한 표는 '미전환'으로 남아 0 이 되지 않는다.
- 새 조사 납품본: '시각화 가능' 판정 표 가운데 사유 없이 표로 남은 것 0건(판정 파일로 증명).
- 기존 G3 검사(`[도판출처]`·`[도판무결박]`) 그대로 통과 — 그림이 늘어도 결박 규칙은 동일.
