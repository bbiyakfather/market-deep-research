# 1부 — 조사 PRD: BM 조사방법론을 어떻게 조사하나

## 1.1 배경·문제
- 실측: 출연연 BM 중간본 — 양식에서 흘러든 "단가 프리미엄·TCO 제거" 주장이 워커 산출물로 되돌아와 §0 전제가 반증되고 논지를
  교체했다(`reader-goal.md` 운용 규칙 2). 촉매 저감 v3 는 창업팀 관점의 BM 질문이 본문 0회. 체외진단 v15 는 진출지 결정에 상대 기업의
  과금 구조가 빠졌다. 셋 다 "누구에게 무엇을 어떻게 받고 파는가" 를 칸으로 묻는 절차가 mdr 에 없어서 생긴 일이다.
- mdr 현황: 기술사업화 실사 프리셋의 '사업성' 축은 2018 기술가치평가 매뉴얼 체계를 **이름만** 빌렸다. BM 후보 생성·수요기업 탐색·
  상대 BM 해부의 칸·질문·증거원·판정 규칙이 어느 reference 에도 없다. 독자 프리셋 A 기술이전 연구자·B 예비창업자·C 사업화 주관기관
  모두 핵심 메시지에 BM 명제가 들어간다.
- 그래서 **먼저 방법론을 조사**한다. 기억이나 관행으로 모듈을 쓰면 또 하나의 "양식 주장" 이 된다. 조사도 mdr 의 증빙 규칙(원문 재열람·
  URL·열람일, 검색 요약 불인정)으로 한다.

## 1.2 조사 목표 / 비목표
- 목표: 공개자료로 **재열람 가능한** BM 조사·설계·검증 방법론을 모아, 독자 A·B·C 별로 "단계 → 입력 → 작업 → 산출물 → 증거원" 표와
  "공개자료로 닫히는 항목 / 인터뷰·내부자료로만 닫히는 항목" 구분으로 재구성한다. 모듈에 **가져올 것 / 안 가져올 것(이유)** 을 자료마다 적는다.
- 비목표: 특정 기업·기술의 BM 조사(그건 모듈이 할 일) · 유료 DB·로그인 벽·책 전문(열지 않는다, 못 연 것은 '미열람' 으로 기록) ·
  인터뷰 수행 · 방법론 간 우열 판정(쓸 칸만 고른다) · 한국어 번역본 창작(원문 문장 인용).

## 1.4 출처 규칙 (mdr `source-ladder.md` 를 조사에도 적용)
- 등급: **E1** 원문 URL 을 열어 문장·표를 다시 캡처할 수 있음 → 사실 / **E2** 검색 발췌·2차 요약만 → 모듈 판단 기준으로 쓰지 않음 /
  **I** 고객·구매자·내부 운영의 말·행동 없이는 안 닫힘 / **X** 비공개·페이월·로그인·이번에 못 엶. 등급 없는 숫자·문장 금지.
- 숫자는 발행 연도·표본·지역을 함께. 벤치마크(Bessemer 2021·YC Top 100·NRF 반품률·BIO 성공률)는 "질문 설계용" 이지 한국 합격선이 아님을 매 숫자 옆에.
- 라이선스: 저장소 README 문장은 라이선스가 명시된 것만 인용, 없으면 항목명+URL 만. 캔버스 도형·패턴 카드(Strategyzer·BMI Lab)는 복사하지 않는다.
- 강방어 사이트(McKinsey 등)가 안 열리면 `(검색 요약 기준)` 표기 후 E2 로 둔다. 우회·로그인·가입·결제·메일 금지.

## 1.5 산출물 형식 (조사 1건당 Markdown 1파일, 300~600줄)
① 방법론·자료 목록표(출처·연도·URL·독자 매핑·E 등급) ② 원문에서 확인한 절차(단계·표·질문 원문 인용) ③ 독자 A·B·C 별 권장 절차표
(단계·입력·작업·산출물·증거원) ④ 공개자료로 못 닫는 항목 ⑤ 이번에 못 연 출처(2차 조사 입력) ⑥ 모듈에 가져올 것 / 안 가져올 것.
모든 주장 옆 URL. 완료 뒤 링크 전건 HTTP 점검(봇 차단은 별도 재확인).
