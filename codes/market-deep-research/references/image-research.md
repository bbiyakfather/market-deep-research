# image-research — 세부주제 대표 이미지([그림] 도판) 수확·결박

보고서의 각 세부주제(단락)에는 이해를 돕는 대표 도판(지도·인포그래픽·개념도·위성사진·
현장사진)을 결박한다. 전례: 2025-12 PEM 보고서의 REPowerEU 도해·DOE H2Hubs 지도·
인도 NGHM 카드·콜롬비아 인포그래픽(전부 소스 문서에서 수확된 도판).

## 증빙캡처와 구분 (혼동 금지)
| | source_capture(증빙) | 대표 이미지(도판) |
|---|---|---|
| 목적 | 핵심수치 원문 결박 | 단락 주제 이해 |
| 도구 | `capture_pdf.py`·실브라우저 캡처 | `harvest_images.py` |
| 저장 | `_captures/` | `_images/` |
| 게이트 | G2(핵심수치 필수) | 도판게이트(본문 이미지 0장 FAIL) |

## 소스 우선순위 (harvest_images.py)
1. **소스 PDF 도판 크롭** — `pdf <file.pdf>`: 조사에서 확보·발췌한 PDF 를 전수 스캔해
   래스터+벡터 도판 후보를 크롭하고 캡션을 추정(`index.json`). 해당 단락의 근거 문서에서
   나온 도판이라 **출처가 자동 일치** — 항상 최우선. 반복 로고·아이콘·표는 자동 필터.
2. **확보한 웹페이지 이미지** — `page <url>`: 이미 fetch 한 보도자료·공식 페이지의
   og:image·본문 이미지 후보(현장사진·조감도·프로그램 도해 다수).
3. **이미지 검색** — `search "<query>"`: openverse·commons(라이선스 필드 제공)+searx(가용 시).
   질의는 넓게(2~3 단어) 시작 — 과도하게 구체적이면 0건이 정상이다.
4. **자작 대체** — 위에서 못 찾으면 자작 차트(PPT 네이티브)·codex-image 생성으로. 유료
   스톡 무단 사용은 어떤 경우에도 금지.

## 선별·결박 (팀리드 전속)
- 후보는 **팀리드가 Read 로 육안 선별**(단락 주제 일치·품질·워터마크 없음). 자동 삽입 금지.
- 본문 결박: `![...](_images/...)` + `[그림] 제목` 캡션 + **출처**(기관·문서명·페이지 또는 URL) 병기.
  무출처 도판은 본문 사용 불가(증빙과 동일 철칙).
- `_images/IMAGES.md` 인덱스 유지: 파일 | 결박 절 | 출처(문서·p / URL) | 라이선스 판단 | accessed_at.

## 라이선스·안전 규율
- 정부·공공(EC·DOE·PIB·IEA 등) 도판은 기관별 재사용 조건 확인(예: IEA=CC BY 4.0) 후 출처 표기.
- openverse·commons 결과의 `license` 필드를 인덱스에 그대로 기록, BY·SA 조건 준수.
- 다운로드는 SSRF 경계 + 매직바이트(래스터만)·크기 검증 통과분만 저장(`get`).
- HTTP 429(rate limit)·403 은 사유 그대로 기록하고 다음 후보로 — 재시도 남발 금지.
