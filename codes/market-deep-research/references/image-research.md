# image-research — 세부주제 대표 이미지([그림] 도판) 수확·결박

보고서의 각 세부주제(단락)에는 이해를 돕는 대표 도판(지도·인포그래픽·개념도·위성사진·
현장사진)을 결박한다. 전례: 2025-12 PEM 보고서의 REPowerEU 도해·DOE H2Hubs 지도·
인도 NGHM 카드·콜롬비아 인포그래픽(전부 소스 문서에서 수확된 도판).

## 증빙캡처와 구분 (혼동 금지)
| | source_capture(증빙) | 대표 이미지(도판) |
|---|---|---|
| 목적 | 핵심수치 원문 결박 | 단락 주제 이해 |
| 도구 | `capture_pdf.py`·실브라우저 캡처 | `harvest_images.py` |
| 저장 | `_captures/` | `_images/` |
| 게이트 | G2(핵심수치 필수) | G3 도판검사(본문 대표 이미지 0장 FAIL) |

## 도판 확보 우선순위
0. **워커 `## FIGURES` 신고분** — 원문을 직접 읽은 워커가 남긴 `WHERE`·`SOURCE_URL`부터
   수확한다. 문맥과 캡션을 이미 확인한 후보라 해당 단락에 가장 정확하고, 같은 원문을 팀리드가
   처음부터 다시 탐색하는 낭비를 막으므로 PDF 전수 스캔보다 먼저 처리한다.
1. **소스 PDF 도판 크롭** — `pdf <file.pdf>`: 조사에서 확보·발췌한 PDF 를 전수 스캔해
   래스터+벡터 도판 후보를 크롭하고 캡션을 추정(`index.json`). 해당 단락의 근거 문서에서
   나온 도판이라 **출처가 자동 일치** — 워커 신고분 다음 우선. 반복 로고·아이콘·표는 자동 필터.
2. **확보한 웹페이지 이미지** — `page <url>`: 이미 fetch 한 보도자료·공식 페이지의
   og:image·본문 이미지 후보(현장사진·조감도·프로그램 도해 다수).
3. **이미지 검색** — `search "<query>"`: openverse·commons(라이선스 필드 제공)+searx(가용 시).
   질의는 넓게(2~3 단어) 시작 — 과도하게 구체적이면 0건이 정상이다.
4. **자작 차트(최후 수단)** — 위 0~3을 모두 소진한 뒤에만 `scripts/make_chart.py` 를 쓴다.
   ```
   python make_chart.py bar  <work_dir> --facts F001,F002 --title "제목" [--out assets/<slug>.svg]
   python make_chart.py line <work_dir> --facts F010,F011,F012 --title "제목" [--out ...]
   ```
   값은 CLI 로 직접 받지 않고 `facts.jsonl` 의 `confirmed` fact 에서만 읽는다. 임의 숫자를 그려
   출처·F태그 없는 차트가 본문에 들어가는 일을 구조적으로 막기 위한 설계다. 유료 스톡 무단
   사용은 어떤 경우에도 금지.

## 선별·결박 (팀리드 전속)
- 후보는 **팀리드가 Read 로 육안 선별**(단락 주제 일치·품질·워터마크 없음). 자동 삽입 금지.
- 본문 이미지 참조 뒤 **2줄 이내**에 `[그림]`으로 시작하고 `출처:`를 포함한 캡션 줄을 둔다.
  하나라도 빠지면 G3가 `[도판출처]`로 FAIL한다 — 무출처 도판은 증빙과 같은 철칙상 본문에
  쓸 수 없고, 거리 제한이 있어야 기계검사가 어느 도판의 캡션인지 모호하지 않게 결박한다.
  ```markdown
  ![](_images/eu-h2-map.png)
  [그림] REPowerEU 수소 회랑 — 출처: EC COM(2022)230 p.14
  ```
- 참조 경로가 `assets/` 이하인 자작 차트는 같은 캡션에 `(Fxxx)` 태그를 최소 1개 둔다. 없으면
  `[도판무결박]`로 FAIL한다 — 차트의 숫자가 `confirmed` fact에서 왔음을 독자가 역추적하게
  하기 위한 결박이다.
- `_captures/` 증빙캡처는 이 도판검사 대상이 아니며 G2가 판정한다. 같은 이미지를 G2와 G3에서
  서로 다른 목적으로 이중 판정하면 증빙캡처에 대표 도판 규율이 잘못 적용되기 때문이다.
- 수확 뒤 `harvest_images.py index <work_dir>` 로 `_images/IMAGES.md` 인덱스를 생성한다:
  파일 | 결박 절 | 출처(문서·p / URL) | 라이선스 판단 | accessed_at. 명령으로 재생성해야 실제
  수확물과 인덱스의 누락·드리프트를 줄일 수 있다.

## 라이선스·안전 규율
- 정부·공공(EC·DOE·PIB·IEA 등) 도판은 기관별 재사용 조건 확인(예: IEA=CC BY 4.0) 후 출처 표기.
- openverse·commons 결과의 `license` 필드를 인덱스에 그대로 기록, BY·SA 조건 준수.
- 다운로드는 SSRF 경계 + 매직바이트(래스터만)·크기 검증 통과분만 저장(`get`).
- HTTP 429(rate limit)·403 은 사유 그대로 기록하고 다음 후보로 — 재시도 남발 금지.
