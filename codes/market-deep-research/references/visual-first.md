# visual-first — 그림이냐 표냐 (표 만능 교정 · [3] 표를 만들기 직전 · G4)

원칙: **시각화할 수 있는 데이터는 그림이 기본, 표는 예외.** 표는 "정리했다"는 느낌을 주지만 독자는 추이·격차·비중을
표에서 읽어내지 못한다(2026-10-08 사용자 지시, 실측·근본 원인은 `docs/prd-visual-first_261008.md`).
출처 순서(원문 도판 → 캡처 → 자작)는 `image-research.md` 가 정하고, 이 문서는 **형식**만 정한다.

## 1. 결정표 — 데이터 형태로 고른다
| 데이터 형태 | 기본 표현 | 대안·조건 |
|---|---|---|
| 시간 추이(3시점 이상) | 선 또는 세로 막대 | 2시점(전년→올해)은 병렬 막대·덤벨 |
| 항목 간 크기 비교(3~20개) | 값으로 정렬한 가로 막대 | 20개 초과는 상위 N + '기타', 전수는 부록 표 |
| 비중·구성 | 100% 누적 막대 | 원그래프는 항목 5개 이하·합 100% 일 때만 |
| 수치 범위의 분포 | 히스토그램·점 분포 | 구간별 편수 표는 부록 |
| 두 변수의 관계(로딩 vs 내구 등) | 산점도(기준선·영역 표시) | 점 20개 미만이면 라벨 붙인 산점도 |
| 단계·일정·경로 | 타임라인·흐름도 | 단계 3개 이하는 문장 |
| 국가·지역별 값 | 지도(위치가 의미 있고 5개 이상) 또는 막대 | 지도는 값 라벨 필수 |
| 정성 매트릭스(국가×항목 ○△×) | 표 | 서열형이면 히트맵 |
| 식별자·허가번호·주소·텍스트 속성 | 표 | — |
| 정확한 값 참조가 목적(원자료) | 부록·붙임 표 | 본문엔 그림 + 핵심 수치 문장 |
| 행 2개 이하 | 문장 | — |

## 2. 표가 남는 경우(§1 마지막 세 행 + 아래)
- 열마다 속성 성격이 달라 한 축에 못 올리는 비교표(경쟁 비교표 등).
- 그림을 넣었으면 같은 데이터의 표는 본문에서 뺀다(둘 다 두면 쪽만 늘고 독자는 어느 쪽을 읽을지 모른다). 원자료가
  필요하면 붙임·엑셀.
- 산문 나열(3항목 이상·규제 구조·후보 목록)은 여전히 표 또는 인포그래픽으로 — 이 문서가 금지하는 것은 '수치 데이터를
  표로 두는 것'이지 '산문을 표로 바꾸는 것'이 아니다.

## 3. 차트 최소 규칙(증빙은 그대로)
- 값은 `confirmed` fact 에서만. 캡션 `[그림] 제목 — 출처: …` + `(Fxxx)` 최소 1개(`image-research.md` 결박 규칙 그대로).
- 흰 배경·무장식, 글자 9pt 이상, 막대 20개 이하, 한국어 범례·단위·값 라벨, 전년=회색·올해=강조. 그 외 색·형태
  휴리스틱은 `dataviz` 스킬(인쇄물이라 다크 팔레트·툴팁 규칙은 적용하지 않는다).
- matplotlib 범주축은 **위치 인덱스 + `set_yticklabels`** — 문자열 라벨을 직접 넘기면 같은 문자열이 한 막대로 병합돼
  값이 한 칸씩 밀린 사고(2026-08-07).
- 생성 후 팀리드가 Read 로 연다 — 스크립트 성공 ≠ 그림 정상.
- 도구: `scripts/make_chart.py`(막대·선, facts.jsonl 직결) → 그 외 유형은 matplotlib. 스크립트와 출력 PNG 모두
  `assets/` 에 둔다(다른 폴더면 `[도판무결박]` 검사를 비켜 간다), 값 상수 옆에 F-ID 주석.

## 4. 운영
- 작성자 brief 고정 문구(`agent-briefs.md` 작성자 절): "수치 데이터는 그림이 기본. 표를 만들기 전에 `visual-first.md`
  결정표로 형식을 정하고, 표로 남기면 사유를 `audit/visual-decisions.json` 에 적는다."
- [3] 끝·G4 전, **report.md 와 납품 원고 `manuscript/*.md` 모듈마다**: `python scripts/visual_audit.py <md> --decisions
  audit/visual-decisions.json` — 행 3개 이상·수치열 1개 이상(연번·출처 열 제외)을 후보로 뽑아 제안 형식을 붙인다.
  해결 = `keep` + 사유. `chart` 는 표를 실제로 지워 후보에서 사라져야 해결(남아 있으면 '미전환'). **미결 0건**이 G4
  조건 — 문서 규칙이라 `gates.py` 가 강제하지 않으니 리드가 출력을 G4 영수증 evidence 에 붙인다. 부록 마커 뒤는 제외.
- 납품 원고: 증빙판의 근거표(3부)·지표표(4부)는 검증 구조라 그대로 옮기지 않는다 — 수치는 그림 + 문장, 원자료는 붙임
  (`mdr-hwpx/references/deliverable-rules.md`).
