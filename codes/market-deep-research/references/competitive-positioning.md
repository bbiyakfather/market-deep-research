# competitive-positioning — 경쟁 대안 지도 · 비교 항목 · 포지셔닝 서술 (§6 의료기기·IVD 부록)

**로드 시점**: G0 에서 경쟁·포지셔닝이 조사 핵심으로 확정됐을 때, 그리고 경쟁 챕터 서술·claim-review 직전. 증빙(F태그·재열람·캡처)은 MDR 엔진이 하고, 이 문서는 **무엇을 어떤 칸으로 비교하고 대안·열세를 어디에 쓰는가**만 정한다. §1~§5 는 도메인 중립, §6 은 의료기기·IVD 일 때만 읽는다. 축 이름은 `report-format.md` 에서만 정의한다 → 경쟁 서식은 새 축이 아니라 해당 축 챕터(기술사업화 실사는 시장성 축) 안의 하위 템플릿이다.

## 1. 경쟁 대안 지도 (대안이 먼저, 제품은 나중)
1. **job 한 줄**: "누가 무엇을 더 빠르게·싸게·안전하게 하려는가" 형식, 근거는 업계 표준·가이드라인·규정 원문(인터뷰는 attribution) → 이 문장이 경쟁 범위를 정한다.
2. 아래 4유형을 **전부 행으로** 둔다.

| 유형 | 정의 | 서술 규칙 |
|---|---|---|
| 현상 유지 | 아무것도 도입하지 않음 | 도입을 미루는 이유는 규정·가이드라인 또는 인터뷰 attribution 으로만 |
| 기존 방식(표준 절차) | 현행 절차·기존 설비 | 절차·기준값은 가이드라인 원문에 결박 |
| 직접 경쟁 | 같은 용도·대상·사용 현장 | 제품 단위 식별자(entity-identity) |
| 간접 대체 | 다른 원리로 같은 job | 직접 경쟁과 같은 열에 섞지 않는다 |

3. 못 찾은 유형·칸은 고객 표에 **`미확인`** 만 쓴다. 조회 DB·검색식·조회일은 negative_search 증거와 audit 에 두고, 의사결정에 영향 주는 공백만 9부에 한 줄. 서로 다른 검색식 3회 이상 후에야 미확인으로 확정한다.
4. **열세 시나리오**: 현상 유지·기존 방식 행을 포함해 "이 대안이 더 나은 경우"를 1건 이상 쓴다. 전환장벽은 기술(연동·설비)·계약(약정·입찰)·제도(보상·인증)로 나눈다.

## 2. 비교표 서식 · 운영 규칙
- 열은 **사실 블록**(식별자·허가·성능·가격·설치기반, 셀마다 (Fxxx))과 **분석 블록**(우리가 나은 곳/그들이 나은 곳)으로 분리, 전체 6~8열(F태그 재검증 비용 통제). 궤적·안전성 등 나머지는 1쪽 프로파일 부록(`<!-- FACTSHEET:APPENDIX -->` 뒤, 부록 하위 헤딩으로 G0 승인 목차에 미리 적는다. 값·단위 검증은 본문과 동일).
- 우리 행의 계획서 목표값은 `목표(계획서 인용)` 로 표기, 현재 역량 문장과 섞지 않는다. 비교는 동일 지표·동일 조건만, 정의가 다르면 다른 claim_key(definition 기록).
- **source_role/독립성**: 제조사 보도자료 = `source_role=보도자료`, IFU·카탈로그 = `source_role=원출처`, 둘 다 `grade.independence=D`. 허가·인증번호·공정가격(의료는 수가)은 규제기관·고시 원문이 원출처.
- **risk:high** = '유일·최초·국내 없음' 서술, 점유율·순위, 보상·가격 적용 여부 주장 중 **본문 우열 서술에 인용된 셀**. 허가번호·성능값은 normal 로 두고 규제 DB 원문+캡처만 요구(셀 수십 개 high 화 금지).
- 로그인·동적 DB 는 캡처 가능 여부를 사전 점검, 불가하면 인용하지 않고 `미확인`(정책선: 무단 우회 금지).
- 경쟁 범위가 정의에 따라 갈리면 두 범주 병기, 비교 기준은 계획서 목표치가 아니라 경쟁사·시장 — `reader-goal.md` 관점 규칙.

## 3. 조사 웨이브 (병렬 조사원 TASK 단위, 축은 재정의하지 않음)
| 웨이브 | 질문 | 반환 |
|---|---|---|
| 1 대안·경쟁 식별 | job 에 쓰이는 모든 대안, 국내 후보 우선 탐색 | 후보 목록 + EXPAND 리드 |
| 2 항목 채우기 | 후보별 §2 비교 항목·§6 근거원 | 제품 단위 EVIDENCE |
| 3 진입 경로·구매 구조 | 진입 경로별 요건·소요기간, 구매·사용·지불·규제 주체별 전환 트리거 | EVIDENCE + 인사이트(추론 구분) |
| 4 신흥·반증 | 신흥 진입자, 포지셔닝 가설 반증 검색 | negative_search 포함 |

스폰 메시지 `2. 범위` 필수: 제품명·모델·규제·인증코드(해당 시)·기준일.

## 4. 포지셔닝 각색 (Dunford 중 쓸 것만)
쓰는 것: ①경쟁 대안(§1) ②고유속성(대안에 있으면 table stakes) ⑤카테고리(진입 경로 비교표) ⑥트렌드(선택). 가치테마·최적고객은 구매·사용·지불·규제 주체 4분해 표로 대체.

| 결과물 | 지위 | claim_type | 표지·결박 |
|---|---|---|---|
| 대안 존재·허가번호·성능값·가격 | 사실 | observed | 셀마다 (Fxxx) |
| 우열·위협도·집중도·진입장벽·카테고리 적합 | 분석 | derived / hypothesis | 문장 앞 `(분석)`(상충 병기 시 `[상충] (분석)` 순) + 근거 F-ID + required_qualification, 판정 기준은 표 하단 명시 |
| 포지셔닝 방향 문장 | 권고 | recommendation | 10부(조사팀 인사이트) 안 권고 1절, 칸마다 근거 표 번호+F-ID |

- '유일' 대신 "조사 범위(DB·기간·검색식) 내에서 확인된 바로는". Onliness 시험은 audit 에서만.
- '경쟁자 없음'·로드맵 기반 우위 금지, 단건 사례의 시장 일반화 금지. 스키마 enum·필드는 새로 만들지 않는다(새 본문 표기는 `(분석)`·`목표(계획서 인용)` 2개만).

## 5. G3 직전 팀리드 점검 (본문↔비교표 대조)
1. 비교표 제품이 본문에 모두 서술됐는가 2. 본문 우열이 표 F값과 일치하는가 3. 같은 보도자료의 재전재를 독립 2출처로 세지 않았는가 4. 허가·가격 셀에 valid_at/observed_at(시간증거)이 있는가 5. 포지셔닝 주장이 2개 이상 표로 지지되는가.
셀 값 자체는 fact 별 by=lead 재열람(reread_sha256) 기록으로 확인한다 — 이 점검은 그 기록을 대신하지 않는다.

## 6. 부록 — 의료기기·IVD 병원 B2B 비교 항목과 1차 근거원
| 비교 항목 | 확인 내용 | 1차 근거원 |
|---|---|---|
| 인허가 | FDA 510(k)/De Novo/PMA 번호, MFDS 품목허가·인증·신고번호·등급, CE, 허가 적응증·검체, UDI-DI(식별코드) | 규제기관 DB 원문 (CE 는 EUDAMED 또는 인증서·적합성선언 원문, 없으면 미확인) |
| SW 인허가(SaMD) | AI·판독 SW 의 별도 허가·디지털의료기기 분류 | MFDS 의료기기전자민원시스템(emedi) 제품정보(디지털의료기기 구분, 있으면)·FDA AI-Enabled Medical Devices 목록 |
| 측정 방식 | 단회/반복/연속, 지속시간, TAT, 채취 침습성, 마커 패널 | 허가 요약서·IFU·논문 |
| 사용 현장·운영 요건 | 사용 현장(예: 응급실 POC / 중앙검사실), 필요 인력·검사 복잡도(미국 CLIA waived/moderate/high) | 허가 문서·가이드라인 |
| 성능 | LoD·CV·cutoff 정의(해당 시, 예: hs-cTn 의 99th percentile URL·그 농도의 CV), 민감도/특이도, 대상 집단 | 허가 요약서·논문 (정의 기록, 검체 다른 값의 직접 우열 비교 금지) |
| 임상근거 | 등록·상태·결과, 가이드라인 포함 여부 | ClinicalTrials.gov·CRIS·MFDS 임상시험 승인 현황·PubMed·학회 가이드라인 |
| 수가·급여 | 행위 코드·점수·금액, 신의료기술평가 이력 | 보건복지부 고시(행위 급여·비급여 목록표, HIRA 게시)·NECA 평가 결과·해외 CMS(IVD 는 CLFS) |
| 가격·TCO | 검사당 단가, 장비·시약 계약형태, 낙찰가 | 조달청·입찰공고 (없으면 미확인, 추정 금지) |
| 설치기반·유통 | 도입 병원·대수, 대리점, LIS 연동 | IR·입찰·보도자료(독립성 D) |
| 특허 | 출원인·청구항 중복·존속기간 | KIPRIS·Patent Landscape (침해·FTO 결론 금지) |
| 국내 후보 발굴 | 해당 제품군(예: 심장표지자) | MFDS 허가목록·KIPRIS 출원인·NTIS·코스닥/DART IR |

진입 경로 = **허가 경로**(동등성: 510(k)·MFDS 동등제품 / 신규: De Novo·PMA·MFDS 임상자료 허가, 혁신의료기기 지정 여부는 가속 표시) × **보상 경로**(기존 수가 코드 적용 / 신의료기술평가 후 수가 신설 / 평가 유예·혁신의료기술 트랙). 요건·기간은 사실(observed, 셀마다 Fxxx), 추천은 권고(recommendation, 10부 1절). 인터뷰는 직군·인원·일자·질문을 명시한 attribution 으로만 쓴다.

## 7. 쓰지 않는 요소
Knowledge-Based 모드·프록시 추정·H/M/L 신뢰도·출처 Tier(원문 미확인 수치 폐기와 충돌), 리뷰·포럼 마이닝·가격 심리·SEO(근거원 없음), 배틀카드 반론 응대·Moore/Neumeier 본문 문장·태그라인(과업 범위 밖·과장 위험), 별도 검증 에이전트·깊이 점수·Cross-Wave Connections 공식(G0~G5 와 중복).
