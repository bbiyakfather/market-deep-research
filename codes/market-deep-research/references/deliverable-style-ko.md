# deliverable-style-ko — 한국어 납품 보고서 문체·문단·인용 규칙

증빙형 조사 결과(`report.md`)를 **정부사업·기업 납품 문서**로 옮길 때 적용하는 서식 규칙.
조사 단계의 서식(근거 ID 결박·1줄 1사실)과 납품 단계의 서식은 목적이 달라 **반드시 변환**해야 한다.

**적용 시점**: 한국어 납품 문서(hwpx/docx/발표자료)를 만들 때, 그리고 고객이 읽을
`report.pdf` 를 쓸 때. 내부 audit 번들에는 적용하지 않는다.

---

## 0. 가장 흔한 실패 — 과잉 축약

조사 단계에서 G3 게이트(수치↔근거 1:1 결박)를 통과시키려 문장을 잘게 쪼개면,
그대로 납품했을 때 **뼈대만 남아 맥락이 사라진다**. 실측된 실패 사례:

```
✗ 조사 서식 그대로 납품
- 프로젝트 수 감소분 5건 (F007)
- 설비용량 감소분 1,231MW (F008)
- → 신규 등재가 45건 늘었음에도 파이프라인은 순감소

○ 납품 서식으로 변환
- IEA 데이터베이스에 새로 등재된 PEM 프로젝트는 423건에서 468건으로 45건 증가하였으나,
  실제 가동을 향해 움직이는 파이프라인은 206건에서 201건으로 축소되어 발표 물량과 실행
  물량이 서로 반대 방향으로 움직이는 국면에 진입
```

같은 사실이지만 전자는 **숫자만 던지고**, 후자는 그 숫자의 의미가 문장 안에 있다.
납품 문서의 독자는 근거 대장을 볼 수 없으므로 본문이 스스로 설명해야 한다.

## 1. 문단 = 3층 세트 (고정)

```
(키워드) 주제 문장
- 주제 세부 내용 (1)
- 주제 세부 내용 (2)
- 주제 세부 내용 (3)
[근거 자료]  보고서 캡처 · 뉴스 캡처 · 세부내용 표 · 인포그래픽
```

**3층째 표기는 실물에서 `* 출처 :` 가 아니다**(9절 실측). 도판은 `[그림] 캡션`,
표는 `<표> 캡션` 을 달고, 출처는 **문서 끝 `참고문헌 :` 절에 일괄**한다.
표 하단 `출처: 기관명 (단위: …)` 은 BM보고서에서만 확인됐다.

- **모든 서술 문단이 이 세트를 이룬다.** 세부만 있고 근거자료가 없거나, 근거자료만 있고
  세부가 없는 문단은 만들지 않는다.
- 근거 자료는 문단이 주장하는 내용을 **직접** 뒷받침해야 한다. 주제와 느슨하게만 관련된
  범용 도판은 넣지 않는다(실측 피드백: "그다지 연구자에게 참고될만한 자료는 아닌거 같음").

### 위계 (원문 실측)

| 수준 | 표기 | 용도 | 평균 분량 |
|---|---|---|---|
| 1 | `❍` | 결론 문장 (키워드 + 주제) | 100~130자 |
| 2 | `-` | 근거·세부 | **90~130자** |
| 3 | `·` | 최하위 나열 | 짧게 |
| 별도 | `* (사례)` | 구체 사건 삽입 | — |

- **한 불릿에 2~3개 절이 들어가는 것이 정상**이다. 잘게 쪼개지 않는다.
- `※` 는 쓰지 않는다. 원문자 `①②③` 는 순서가 있는 열거에만.
- `- 항목명 : 설명` 콜론 구조는 전체의 2% 수준 — 예외적 패턴이니 남발 금지.

## 2. 키워드(라벨)

- 2~6자 명사구. **결론은 라벨 밖 본문에** 쓴다.
- **라벨을 재사용하지 않고 맥락마다 새로 짓는다** (실측: 197개 중 고유 140종).
- 자주 쓰이는 예: (인프라) (전략적 의의) (최종 수요처) (정책적 맥락) (목표) (정책 리스크)
  (수요처) (기술구성) (재원 조달) (시사점) (제도 도입) (추적 부품 지정)

## 3. 종결 어미 — 명사형

`~할 예정 / ~추진 중 / ~고 있음 / ~될 예정 / ~이 목표 / ~로 전환 / ~진행 중 / ~을 시사 /
~로 부상 / ~예상됨`

- "~합니다 / ~한다" 금지.
- **종결형은 문서 축에 따라 갈린다**(9절 실측). 하나로 통일하지 말 것.

| 축 | 지배적 종결 | 예 |
|---|---|---|
| 시장보고서 | **체언 종결**(서술어를 아예 끊음) | `~로 전망` `~할 것으로 예상` `~에 기인` `~을 차지` `~보유` `~중` |
| BM보고서 | **용언 명사형** | `~하고자 함` `~할 계획임` `~기대됨` `~예정임` `~목표로 함` |

  시장보고서에 `~함/~임` 을 쓰면 문장이 늘어져 축이 흐려지고, BM보고서에 체언 종결을
  쓰면 자사 의지 진술이 남의 일처럼 읽힌다. **외부 사실은 끊고, 자사 계획은 맺는다.**

## 4. 인용 — 조사 서식과 가장 크게 갈리는 지점

| 위치 | 방식 |
|---|---|
| 문장 도입 | **`기관명에 따르면,` 이 실물의 주력 방식**(9절 실측). `OECD에 따르면, 2023년 미국의 1인당 건강 지출은 12,555달러로…` |
| 문서 말미 | `참고문헌 :` 절에 `• 기관. (연도, 월). 제목. 출처. Retrieved from …` 로 일괄 |
| 표 하단 | `출처: 기관명 (단위: 억 달러)` — BM보고서에서 확인 |
| 본문 각주 `n)` | 용어·기관 해설 전용. **다만 실측 3건 모두 각주를 쓰지 않았다** — 용어는 본문 괄호 병기로 처리 |
| 본문 | **URL·근거 ID(F###)를 절대 노출하지 않는다** |

- 용어 병기 실측: `미주신경 자극기(Vagus Nerve Stimulator)` · `연평균 성장률(CAGR)` ·
  `이산화티타늄(TiO₂)` · `자정(Self-Cleaning)` · `수평연속주조(HCC)`.
  **한글명 먼저, 괄호에 원어·약어**가 순서다. 첫 등장에만 붙이고 이후엔 약어만 쓴다.

각주 예시(용어 해설):
> `1)` IEA(국제에너지기구)가 2021년부터 매년 발간하는 수소 산업 연차 보고서로, 각국 정부·
> 기업이 제출한 프로젝트 데이터를 집계해 생산·수요·투자·정책 현황을 종합 분석

- **기관·약어가 처음 등장하면 반드시 정체를 밝힌다.** 각주 또는 본문 삽입 어느 쪽이든,
  풀네임·한글명·성격(정부기관/민관파트너십/업계협회/국책기관)을 명시한다.
  본문 삽입 예: "bp는 원래 영국 런던에 본사를 둔 글로벌 종합 에너지 기업으로, …"
- 인용 출처 유형: 학술논문(저자,「학술지」,권호,면) · 업계협회 · 정부공공기관 · 컨설팅사

## 5. 근거 ID(F###) 변환 규칙 — G3 통과 후 필수 단계

조사용 `report.md` 는 G3 게이트 요건상 본문 수치마다 `(F###)` 를 결박한다.
납품본은 이를 **반드시 걷어낸다**.

```
조사본 report.md  ──(G3 통과·manifest 봉인)──> 근거 추적은 audit/ 에 보존
      │
      └──> 납품본: (F###) 제거 · 문단 3층 세트로 재구성 · 각주는 용어해설로 전환
```

- 근거 추적성은 `audit/facts.jsonl` + `manifest.json` + `_captures/` 로 유지되므로,
  본문에서 ID를 지워도 검증 가능성은 손상되지 않는다.
- 납품본 부록에 "근거 자료 목록"(출처·발간기관·확인일)을 붙이는 것은 허용.
  단 F번호 자체는 노출하지 않는다.

## 6. 표

- **사실 열만.** 해석·분류 열(예: '경성 종결', '위험 등급')을 만들지 않는다.
  분류가 필요하면 사유 셀에 서술로 녹인다.
- 3항목 이상 나열이나 규제 구조는 서술 대신 표로 정리한다.
- 표 하단에 `* 출처 :` 또는 `* 기준 :` 표기.

## 7. 개별 대상 프로파일 양식 (프로젝트·기업·기관 공통)

기관·기업 실사, 프로젝트 동향 등 **개별 대상을 반복 서술**하는 장에 적용하는 고정 3부 구조.

```
1.1 대상명 (국가)
(1) 개요
  ❍ [위치·규모·성격 한 문장]
    - [목표 시점 / 투자자 / 지원 프로그램]
    - [사업주 기업 소개 — 본사·사업규모·전략]
  <표> [대상명] 개요
     구분 | 사업 내용
     사업개요 / 사업기간 / 총 사업비용 / 프로젝트 회사 /
     사업주 / 컨소시엄 / 시행사 / 정부 예산지원        ← 8항목 고정
     ※ 컨소시엄은 `- [국가] 기업명 (역할) : 세부` 형식
  ❍ (라벨) [주제별 서술]
(2) 진행 현황
  ❍ [현재 상태]   - [FID·착공·시운전 일정]
  ❍ [향후 단계]
  [그림] 캡션
(3) 시사점
  ❍ (정책적 맥락) …
  ❍ (전략적 의미) …
```

- (3) 시사점 절은 **항상 라벨로 시작**한다.

## 8. 작성 전 체크리스트

- [ ] 모든 서술 문단이 `(키워드) 주제 → 세부 복수 → 근거자료` 3층 세트를 갖췄는가
- [ ] 세부 불릿이 90~130자로 맥락을 담고 있는가 (뼈대만 남은 문장이 없는가)
- [ ] 본문에 `(F###)`·URL 이 남아 있지 않은가
- [ ] 처음 등장하는 기관·약어에 정체 설명이 붙었는가
- [ ] 각주가 용어 해설로만 쓰였는가 (출처 인용에 쓰이지 않았는가)
- [ ] 도판·표마다 `* 출처 :` 가 붙었는가
- [ ] 도판이 해당 문단 주장을 **직접** 뒷받침하는가
- [ ] 표에 해석·분류 열이 섞이지 않았는가
- [ ] 같은 결론이 두 번 나오지 않는가
- [ ] 조사 과정 흔적(조사일·재검증·"1차 자료 미확인"·"상세는 X장 참조")이 본문에 없는가
- [ ] 문서 축(시장보고서 / BM보고서)에 맞는 종결형·출처 표기를 썼는가 (9절)

```

```

```
2.x.y 국가명 시장

❍ (시장 전망) [성장률·규모 한 문장]

```

기업 단위 반복 블록(고정):

```
2.x. 기업명(국가)
❍ (회사개요)   - (사업 분야)  - (보유 설비)  - (네트워크)
❍ (매출액)
❍ (보유 제품군)  + <표> 보유 제품 포트폴리오(기업명)
❍ (R&D 현황)    + <표> 제품 개발 현황(기업명)
❍ (판매전략) / (성장전략)
```

- **2절 "라벨 재사용 금지"에는 예외가 있다.** `(시장 특징)`·`(시장 전망)`·`(회사개요)`·
  `(매출액)` 같은 **구조 라벨은 국가·기업마다 반복**되며 색인 역할을 한다.
  재사용을 금지하는 건 내용 라벨뿐이다.
- **수치를 반올림하지 않는다**: `239억 4,710만 달러` · `59.1%` · `CAGR 12.1%`.
- 불릿 길이 실측 **60~150자** — 1절이 정한 90~130자보다 폭이 넓다.

### 9-2. BM보고서 골격 — 고정이 아니다

| 위계 | `□` → `-` → `•` | `가.` → `(1)` → `❍` → `-` |
| 표 출처 | `출처: Verified Market Research (단위: 억 달러)` | **없음** |
| 도판 | `[그림] 캡션` 있음 | **없음** |
| 불릿 | 100~250자 | 200~400자 |

**신규 작성은 알로이코어랩스판(4장)을 기준으로 잡아라.** 출처를 달고 도판을 붙이며
문장이 짧다 — 1~8절 규칙에 더 가깝다.

큐레온판 8장은 확장형이나 **품질 결함이 실측되므로 그대로 베끼지 말 것**:

- `(6) 2026년 **이차전지** 산업 전망` 이 **광촉매 보고서**에 들어 있다 — 타 문서 복붙 흔적
- 절 번호 `(6)(7)` 이 한 장 안에서 두 번 반복
- `[표] 연도별 매출 목표` 제목이 매출표·영업이익표에 중복
- 탈자·오타: `~하고자 하.` · `창출하묘` · `단계로소` · `향상시키고이를`
- 표에 해석 열(`차별화 및 경쟁력`)이 섞여 **6절 위반**

두 판본의 교집합(이건 고정으로 봐도 된다):

```
표지    비즈니스모델 분석 보고서 / 대상 기업명 / 날짜 / 발행사   ← 4단
Ⅰ. 회사 개요   1. 기업 일반현황 — 가. 회사 개요 / 나. 대표자 인적사항 / 다. 경영진 현황
Ⅱ. 사업계획   1. 사업개요 → 2. 시장현황·전망 → … → (마지막 장) 기대효과
```

- **Ⅱ.2 시장현황 장은 시장보고서의 축약판이다.** 두 축이 겹치는 유일한 지점이니
  이 장만은 시장보고서 서식(체언 종결·`출처:` 표기·연도별 CAGR 표)을 그대로 쓴다.

### 9-4. BM보고서에는 두 종류가 있다 — **기업 대상 / 기술 대상**

9-2 의 한글 BM보고서 말고 **PPT 형식이 따로 있고, 골격이 전혀 다르다.**
둘을 같은 문서로 착각하면 안 된다. **주어가 다르기 때문이다.**

| | 한글 BM보고서 | PPT BM보고서 |
|---|---|---|
| 주어 | **기업** (창업기업의 사업계획) | **기술** (보유 기술의 이전 마케팅) |
| 대상 예 | 큐레온 · 알로이코어랩스 | 실리콘-그래핀 음극재 · 웨어러블 로봇 |
| Ⅰ장 | 회사 개요(대표자 인적사항까지) | **사업화 니즈** — 왜 이 기술이 필요한가 |
| 분량 | 20~35쪽 | 22~26슬라이드 / 8.8~13.5천자 |

PPT 골격(실측, `1. (비즈니스모델 보고서) 고용량_고안정성 이차전지용 음극재 제조기술.pptx`):

```
Ⅰ. 사업화 니즈        기존 소재의 한계 → 대체 필요성 (2~3슬라이드)
Ⅱ. 사업화 아이템      1. 사업화 기술개요   2. 기술특징 및 장점   3. 응용분야
                      4. 기술완성도(TRL 1~9 표 + 현재 위치 표시)
                      5. 기술이전 자산 현황(특허 표: 명칭·출원번호·상태·소유권자)
                      6. 산-연 협력 추진방안(PoC → 기술이전 → 상용화 R&D 타임라인)
Ⅲ. 사업화 기회요인    정책동향 · 시장동향 · 사업화 현황
Ⅳ. 비즈니스 모델
```

**슬라이드 한 장의 문법이 1절 3층 세트와 정확히 일치한다.** 오히려 여기가 가장 순수한 형태다:

```
■ 흑연 음극재의 한계로 차세대 고성능 대체 소재의 필요성      ← 헤드라인(= 키워드 주제문)
  전기차(EV), 에너지저장장치(ESS), 드론 등에서 배터리의 고용량화∙소형화 요구가
  급증하면서, 현재 상용 흑연 음극재(이론용량 372mAh/g)는 … 한계가 있음   ← 총론
  - 또한, 글로벌 공급망 측면에서 중국의 음극재 시장 독점으로 …            ← 세부
  - 이러한 한계를 극복하기 위해 글로벌 선도기업들은 …                    ← 세부
  [도판 3개] 중국의 음극재 시장 독점 · 글로벌 음극재 수요 전망 · 선도기업 기술 경쟁
```

- 헤드라인은 `■` 로 시작하고 **명사구로 끝낸다**(`~의 필요성`, `~의 한계`).
- 종결은 한글 BM보고서와 같은 **용언 명사형**(`~있음` `~존재함` `~필수적임` `~구현함`).
- **수치를 반드시 붙인다**: `372mAh/g` · `3,600~4,200mAh/g` · `50 사이클 후 46.4%`.
- `→` 로 결론을 유도하는 줄이 슬라이드마다 하나씩 온다.
- TRL 표는 1~9단계를 **전부 싣고** 현재 위치(`개발완료`/`산연협력 스케일업`)만 표시한다.

인접 유형 **`(벨류체인 분석) <박사명>-<기술명>.pptx`** 16종은 같은 계열의 축약판
(8~11슬라이드 / 3.1~6.1천자)이며, 2차 회차에서 **10 → 8슬라이드로 표준화되며 줄었다.**
