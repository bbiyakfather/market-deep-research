# verification-economics — 검증 자원 배분 근거 (팀리드)

원칙: 오류비용 큰 주장(요금·한도 = risk:high 22건)에 검증 자원 집중.
- high 전건: 공식 원문 = 기본소스 직접 재열람 + 조사원 반박검색(counter) 기록. 제3자 재전재는 근거로 불인정.
- normal: 스냅샷 verbatim 자동대조(MATCH/PARTIAL>=0.7) + 팀리드 스캔. MISS는 전건 팀리드 수동 재열람.
- claim-graph 판단: 본 조사의 high-risk는 시장규모류 외부 집계가 아니라 공급자 공식 요금·한도 = 기본소스 자체.
  독립 2그룹 요건은 '공식 원문 + 제3자 교차'로 충족하거나, 공식 단일이면 기본소스 원문성으로 갈음(기권 대신
  Unresolved 병기 원칙 유지 — Figma 월간 청구가는 Unresolved로 남김).
- 검증 불가·모호 3건은 confirm하지 않고 폐기(기권이 정답).
