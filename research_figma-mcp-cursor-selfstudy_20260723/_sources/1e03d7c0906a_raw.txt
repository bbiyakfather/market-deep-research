**Version 2**

## [![Image 1: 링크 복사](https://static.toss.im/icons/svg/icon-link-mono.svg)](https://docs.tosspayments.com/guides/v2/get-started/migration-guide#%EB%A7%88%EC%9D%B4%EA%B7%B8%EB%A0%88%EC%9D%B4%EC%85%98%ED%95%98%EA%B8%B0)마이그레이션하기

최신 버전의 토스페이먼츠 SDK로 마이그레이션하는 방법을 알아보세요.

토스페이먼츠 SDK v1에서는 결제위젯, 브랜드페이, 결제창이 각자 다른 SDK로 분리되어 있었어요. 기존 구매자가 새로운 결제 서비스를 도입하거나 두 개의 결제 서비스를 함께 사용하기 불편했죠.

토스페이먼츠 SDK v2부터는 모든 결제 서비스를 **하나의 토스페이먼츠 SDK**로 사용할 수 있어요. 통일된 인터페이스와 SDK로 더 편리하게 결제를 연동하세요. API에는 변경사항이 없기 때문에 클라이언트 코드만 변경하면 바로 최신 버전의 SDK를 사용할 수 있어요.

SDK를 초기화하는 방법은 다음과 같이 바뀌었어요.

v1

```
<head>
  <script src="https://js.tosspayments.com/v1/payment-widget"></script>
  <script src="https://js.tosspayments.com/v1/brandpay"></script>
  <script src="https://js.tosspayments.com/v1/payment"></script>
</head>
<script>
  const paymentWidget = PaymentWidget(clientKey, customerKey); // 결제위젯
  const brandpay = BrandPay(clientKey, customerKey); // 브랜드페이
  const tossPayments = TossPayments(clientKey); // 결제창
</script>
```

v2

```
<head>
  <script src="https://js.tosspayments.com/v2/standard"></script>
</head>
<script>
  const tosspayments = TossPayments(clientKey); // 통합 SDK
</script>
```

## [![Image 2: 링크 복사](https://static.toss.im/icons/svg/icon-link-mono.svg)](https://docs.tosspayments.com/guides/v2/get-started/migration-guide#%EA%B2%B0%EC%A0%9C%EC%9C%84%EC%A0%AF)결제위젯

토스페이먼츠 SDK를 초기화한 다음에 [`widgets()`](https://docs.tosspayments.com/sdk/v2/js#tosspaymentswidgets) 메서드로 결제위젯 인스턴스를 생성하세요.

v1

`const paymentWidget = PaymentWidget(clientKey, customerKey);`

v2

```
const tosspayments = TossPayments(clientKey);
const widgets = tosspayments.widgets({
  customerKey,
  brandpay?: {
    redirectUrl: 'https://tosspayments.com/auth'
  }
});
```

### [![Image 3: 링크 복사](https://static.toss.im/icons/svg/icon-link-mono.svg)](https://docs.tosspayments.com/guides/v2/get-started/migration-guide#ui-%EB%A0%8C%EB%8D%94%EB%A7%81-%EB%B0%8F-%EA%B2%B0%EC%A0%9C-%EA%B8%88%EC%95%A1-%EC%84%A4%EC%A0%95)UI 렌더링 및 결제 금액 설정

결제 금액을 설정하는 [`setAmount()`](https://docs.tosspayments.com/sdk/v2/js#widgetssetamount) 메서드가 추가되었습니다. [`renderPaymentMethods()`](https://docs.tosspayments.com/sdk/v2/js#widgetsrenderpaymentmethods)를 호출하기 전에 해당 메서드로 반드시 결제 금액을 설정하세요. 결제 UI 렌더 이후에도 할인 쿠폰 등의 이유로 결제 금액이 변경되면 [`setAmount()`](https://docs.tosspayments.com/sdk/v2/js#widgetssetamount) 메서드로 결제 금액을 업데이트할 수 있어요. 따라서 결제위젯 SDK v1에서 제공된 `updateAmount()` 메서드는 토스페이먼츠 SDK v2에서 제공되지 않습니다.

결제 금액을 별도의 메서드로 설정하기 때문에 [`renderPaymentMethods()`](https://docs.tosspayments.com/sdk/v2/js#widgetsrenderpaymentmethods)의 파라미터로 더 이상 결제 금액 정보를 받지 않습니다. 또한, 해당 렌더링 메서드가 비동기적으로 바뀌었습니다. 렌더링이 언제 완료되었는지 편리하게 확인할 수 있기 때문에 결제위젯 SDK v1에서 제공된 `on()` 메서드의 `ready` 이벤트가 제거됩니다.

v1

```
const paymentMethodsWidget = paymentWidget.renderPaymentMethods(
  "#payment-methods",
  {
    value: 10000,
    currency: "KRW",
    country: "KR",
  },
  { variantKey: "widgetA" }
);

paymentMethodsWidget.on("ready", () => {
  // 결제 버튼 활성화
});
```

v2

```
await widgets.setAmount({
  value: 10000,
  currency: "KRW",
});

const paymentMethodWidget = await widgets.renderPaymentMethods({
  selector: "#payment-methods",
  variantKey: "widgetA",
});
```

### [![Image 4: 링크 복사](https://static.toss.im/icons/svg/icon-link-mono.svg)](https://docs.tosspayments.com/guides/v2/get-started/migration-guide#%EC%84%A0%ED%83%9D%EB%90%9C-%EA%B2%B0%EC%A0%9C%EC%88%98%EB%8B%A8-%ED%99%95%EC%9D%B8)선택된 결제수단 확인

[`on()`](https://docs.tosspayments.com/sdk/v2/js#paymentmethodwidgeton) 메서드에 구매자가 선택한 결제수단을 확인할 수 있는 `paymentMethodSelect` 이벤트가 추가됩니다. [결제위젯 Pro](https://docs.tosspayments.com/guides/v2/payment-widget/pro) 커스텀 결제수단 기능에 사용하던 `customRequest`, `customPaymentMethodSelect`, `customPaymentMethodUnselect` 이벤트는 제거됐어요.

v1

```
// 결제위젯 Pro 커스텀 결제수단
paymentMethodsWidget.on("customRequest", (paymentMethodKey) => {
  if (paymentMethodKey === "VOUCHER") {
    // 상점관리자에서 설정한 key값
    // 평생교육바우처로 결제하는 코드
  }
});

paymentMethodsWidget.on("customPaymentMethodSelect", (paymentMethodKey) => {
  if (paymentMethodKey === "VOUCHER") {
    // 평생교육바우처 선택했을 때 바우처 입력 폼을 노출
  }
});

paymentMethodsWidget.on("customPaymentMethodUnselect", (paymentMethodKey) => {
  if (paymentMethodKey === "VOUCHER") {
    // 평생교육바우처 선택을 해제했을 때 바우처 입력 폼을 숨김
  }
});
```

v2

```
paymentMethodWidget.on("paymentMethodSelect", (selectedPaymentMethod) => {
  if (paymentMethodSelected.code === "평생교육바우처") {
    // 커스텀 결제수단
    // 평생교육바우처 안내사항 노출
  }
  if (paymentMethodSelected.code === "카드") {
    // 카드 안내사항 노출
  }
});
```

### [![Image 5: 링크 복사](https://static.toss.im/icons/svg/icon-link-mono.svg)](https://docs.tosspayments.com/guides/v2/get-started/migration-guide#%EA%B2%B0%EC%A0%9C-ui-%EC%82%AD%EC%A0%9C)결제 UI 삭제

생성한 결제 UI의 인스턴스를 삭제할 수 있는 [`destroy()`](https://docs.tosspayments.com/sdk/v2/js#paymentmethodwidgetdestroy) 메서드가 추가됐습니다. 한 페이지 내에서 2 개 이상의 결제 UI를 렌더링할 수 없기 때문에 새로운 결제 UI를 렌더링하고 싶다면 해당 메서드로 인스턴스를 먼저 삭제해주세요.

v2

```
await paymentMethodWidget.destroy();
const paymentMethodWidget = await widgets.renderPaymentMethods({
  selector: "#payment-methods",
  variantKey: "DEFAULT",
});
```

### [![Image 6: 링크 복사](https://static.toss.im/icons/svg/icon-link-mono.svg)](https://docs.tosspayments.com/guides/v2/get-started/migration-guide#%EC%9A%94%EC%95%BD)요약

| v1 | v2 | 설명 |
| --- | --- | --- |
| 동기적 렌더링 메서드 | 비동기적 렌더링 메서드 | [`renderPaymentMethods()`](https://docs.tosspayments.com/sdk/v2/js#widgetsrenderpaymentmethods), [`renderAgreement()`](https://docs.tosspayments.com/sdk/v2/js#widgetsrenderagreement) 메서드가 비동기로 바뀌었습니다. |
| `updateAmount()` | [`setAmount()`](https://docs.tosspayments.com/sdk/v2/js#widgetssetamount) | 결제위젯을 렌더링할 때 받던 결제 금액을 이제 별도로 메서드로 설정하게 되었습니다. |
| `on()` | [`on('paymentMethodSelect', callback)`](https://docs.tosspayments.com/sdk/v2/js#paymentmethodwidgeton) | v1에서 사용하던 `ready` 및 커스텀 결제수단과 관련된 이벤트가 모두 `paymentMethodSelect`로 대체됩니다. |
| - | [`destroy()`](https://docs.tosspayments.com/sdk/v2/js#paymentmethodwidgetdestroy) | 결제수단 UI, 이용약관 UI를 삭제할 수 있는 이벤트가 추가됐습니다. 결제수단 UI와 이용약관 UI는 한 페이지에 각 하나씩만 렌더링할 수 있습니다. |

## [![Image 7: 링크 복사](https://static.toss.im/icons/svg/icon-link-mono.svg)](https://docs.tosspayments.com/guides/v2/get-started/migration-guide#%EB%B8%8C%EB%9E%9C%EB%93%9C%ED%8E%98%EC%9D%B4)브랜드페이

토스페이먼츠 SDK를 초기화한 다음에 [`brandpay()`](https://docs.tosspayments.com/sdk/v2/js#tosspaymentsbrandpay) 메서드로 브랜드페이 인스턴스를 생성하세요.

v1

```
const brandpay = BrandPay(clientKey, customerKey, {
  redirectUrl: "https://tosspayments.com/auth",
});
```

v2

```
const tosspayments = TossPayments(clientKey);
const brandpay = tosspayments.brandpay({
  customerKey,
  redirectUrl: "https://tosspayments.com/auth",
});
```

### [![Image 8: 링크 복사](https://static.toss.im/icons/svg/icon-link-mono.svg)](https://docs.tosspayments.com/guides/v2/get-started/migration-guide#%EA%B2%B0%EC%A0%9C-%EC%9A%94%EC%B2%AD)결제 요청

브랜드페이 메서드에는 크게 두 가지 변화가 있습니다.

첫 번째로는 v1에서 제공되던 `getPaymentMethods()` 메서드가 제거됐어요. 구매자가 등록한 결제수단을 더 이상 확인할 수 없기 때문에 결제를 요청하는 [`requestPayment()`](https://docs.tosspayments.com/sdk/v2/js#brandpayrequestpayment) 메서드에서 특정 결제수단에만 해당했던 아래 파라미터도 모두 제거됩니다.

*   `methodId`
*   `cardInstallmentPlan`
*   `useCardPoint`
*   `discountCode`
*   `cashReceipt`

두 번째로는 결제 금액이 `number`에서 `object`로 바뀝니다. 결제위젯, 결제창과 동일하게 결제 금액, 결제 통화를 객체로 받아요. 하지만 브랜드페이는 아직 국내 결제에만 사용되기 때문에 결제 통화는 항상 `KRW`입니다.

v1

```
await brandpay.getPaymentMethods();
await brandpay.requestPayment({
  amount: 15000,
  orderId: 'XfUu58BNtNf5lbHHkL44p',
  orderName: "토스 티셔츠 외 2건",
  customerEmail: "customer@example.com",
  methodId: "b_aPz8LBLadxD6WVy4",
  useCardPoint: true,
});
```

v2

```
await brandpay.requestPayment({
  amount: {
    value: 15000,
    currency: "KRW",
  },
  orderId: 'XfUu58BNtNf5lbHHkL44p',
  orderName: "토스 티셔츠 외 2건",
  customerEmail: "customer@example.com",
  customerName: "김토스",
});
```

### [![Image 9: 링크 복사](https://static.toss.im/icons/svg/icon-link-mono.svg)](https://docs.tosspayments.com/guides/v2/get-started/migration-guide#%EC%9A%94%EC%95%BD-1)요약

추가로 아래와 같이 단순 메서드 이름 변경 및 메서드가 제거되었습니다.

| v1 | v2 | 설명 |
| --- | --- | --- |
| `getPaymentMethods()` | - | 메서드 제거 |
| `requestPayment()` | [`requestPayment()`](https://docs.tosspayments.com/sdk/v2/js#brandpayrequestpayment) 파라미터 변경 및 제거 | `methodId`, `cardInstallmentPlan`, `useCardPoint`, `discountCode`, `cashReceipt` 파라미터가 제거됩니다. `amount`는 타입이 객체로 바뀌었습니다. |
| `setupPassword()` | [`changePassword()`](https://docs.tosspayments.com/sdk/v2/js#brandpaychangepassword) | 메서드 이름 변경 |
| `setupOneTouchPay()` | [`changeOneTouchPay()`](https://docs.tosspayments.com/sdk/v2/js#brandpaychangeonetouchpay) | 메서드 이름 변경 |
| `isOneTouchPay()` : `boolean` | [`isOneTouchPayEnabled()`](https://docs.tosspayments.com/sdk/v2/js#brandpayisonetouchpayenabled) : `{isEnable: boolean}` | 메서드 이름 및 응답 변경 |
| `toggleOneTouchPay()` | - | 메서드 제거 |
| `requestAgreement()` | - | 메서드 제거 |

## [![Image 10: 링크 복사](https://static.toss.im/icons/svg/icon-link-mono.svg)](https://docs.tosspayments.com/guides/v2/get-started/migration-guide#%EA%B2%B0%EC%A0%9C%EC%B0%BD)결제창

토스페이먼츠 SDK를 초기화한 다음에 [`payment()`](https://docs.tosspayments.com/sdk/v2/js#tosspaymentspayment) 메서드로 결제창 인스턴스를 생성하세요.

v1

`const tossPayments = TossPayments(clientKey);`

v2

```
const tosspayments = TossPayments(clientKey);
const payment = tosspayments.payment({
  customerKey,
});
```

### [![Image 11: 링크 복사](https://static.toss.im/icons/svg/icon-link-mono.svg)](https://docs.tosspayments.com/guides/v2/get-started/migration-guide#%EA%B2%B0%EC%A0%9C-%EC%9A%94%EC%B2%AD-1)결제 요청

[`requestPayment()`](https://docs.tosspayments.com/sdk/v2/js#paymentrequestpayment)는 원래 결제수단, 결제정보 두 가지 파라미터를 받았는데요. v2에서는 두 파라미터를 통합합니다. SDK v2에서는 결제정보 객체 안에 있는 `method` 필드로 결제수단 정보를 추가할 수 있어요. 선택한 `method`에 해당하는 파라미터를 전달해주세요. 예를 들어, 결제수단으로 `CARD`를 선택하면 [`requestPayment()`](https://docs.tosspayments.com/sdk/v2/js#paymentrequestpayment)의 `card` 필드 안에 카드 결제 관련 내용을 전달해야 됩니다.

또 결제정보에서 아래 필드가 제거됩니다.

*   `cultureExpense`
*   `hideMobileAppHeader`
*   `showCustomerMobilePhone`
*   `mobileCarrier`

v1

```
tossPayments.requestPayment("카드", {
  amount: 1000,
  orderId: "xFOSAaxXNZPKeHIkJWm91",
  orderName: "테스트 결제",
  customerName: "김토스",
  successUrl: window.location.origin + "/success",
  failUrl: window.location.origin + "/fail",
});
```

v2

```
payment.requestPayment({
  method: "CARD", // 결제수단
  amount: {
    currency: "KRW",
    value: 50000,
  },
  orderId: "LM5Q0aaQn2SR51o07dslA",
  orderName: "토스 티셔츠 외 2건",
  successUrl: window.location.origin + "/success",
  failUrl: window.location.origin + "/fail",
  customerEmail: "customer123@gmail.com",
  customerName: "김토스",
  customerMobilePhone: "01012341234",
  // CARD 결제에 필요한 정보
  card: {
    useEscrow: false,
    useCardPoint: false,
    useAppCardOnly: false,
  },
});
```

| v1 | v2 | 설명 |
| --- | --- | --- |
| `requestPayment(결제수단, 결제정보)` | [`requestPayment(결제정보)`](https://docs.tosspayments.com/sdk/v2/js#paymentrequestpayment) | 결제수단, 결제정보 파라미터를 통합합니다. SDK v2에서는 결제정보의 `method` 필드로 결제수단을 전달해주세요. |
| - | 결제정보 필드 제거 | `cultureExpense`, `hideMobileAppHeader`, `showCustomerMobilePhone`, `mobileCarrier` |
