에어비앤비 (Airbnb) 웹사이트를 클론 코딩 합니다. 백엔드는 Python, Django, Django REST Framework, Strawberry GraphQL를 사용하고, 프론트엔드로 ReactJS 를 사용합니다. 마켓플레이스의 기능을 구현하여, 유저들은 원하는 숙소를 검색하고, 즐겨찾기에 찜하고, 예약할 수 있으며, 후기를 남기고 이를 확인할 수 있습니다.
또한 숙소 주인은 이미지를 업로드 하고, 숙소의 디테일을 작성하고, 이를 대시보드로 확인할 수 있습니다.
Django 는 핀터레스트. 인스타그램과 같은 유명한 웹 서비스를 구현하는데 쓰이는 파이썬 웹 프레임워크 입니다.현 강의에서는 세계적인 Django 기능 중 하나인 어드민 패널, ORM 및 유저 매니지먼트 기능을 활용합니다.Django + React 조합은 스타트업 업계에서 인기가 많은 스택 중 하나이기도 합니다!
REST 는 API 의 표준이라 할 수 있습니다. 대부분의 iOS 및 Android 애플리케이션은 REST API를 사용하여 백엔드와 통신합니다.현 강의에서는 대부분의 유명 스타트업이 사용하는 Django REST Framework를 활용하여, REST API를 빌드합니다.
API 는 빠르게 발전하고 있고, 이에 따라 더더욱 많은 팀들이 GraphQL을 API로 사용하고 있습니다. 현 강의에서는 REST 뿐만 아니라, Strawberry 를 사용하여 GraphQL API 를 빌드합니다.
React 는 현재 프론트엔드 프레임워크의 제왕입니다. 인터랙티브하고 빠르고 아름다운 웹 어플리케이션을 구축하기 위해 React 를 사용하며, React 의 data fetching 그리고 styling 패키지를 활용합니다.
