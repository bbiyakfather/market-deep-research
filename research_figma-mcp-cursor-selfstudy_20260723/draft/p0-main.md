# Figma MCP × Cursor 셀프 학습 가이드

> 디자인 툴 **Figma**와 AI 코딩 에디터 **Cursor**를 연결해, 코드를 몰라도 웹/앱 서비스를 직접 만드는 법을 배우는 자기주도 학습 가이드입니다. FastCampus 강의 "Figma MCP, Cursor로 1시간만에 만드는 고퀄리티 웹/앱 서비스" 수강생의 보조 자료로, 강의가 다루는 주제를 **공개 자료(공식 문서·무료 강의·튜토리얼)만으로** 복습·심화할 수 있게 구성했습니다.

## 이 가이드 사용법 (3줄)

1. 처음이라면 **1. 시작하기**부터 순서대로 — 환경 세팅이 전체 학습의 절반입니다.
2. 각 페이지의 **[따라하기]** 블록은 실제로 손을 움직이는 부분입니다. "✅ 이게 보이면 성공"으로 각 단계를 확인하세요.
3. 막히면 **7. FAQ & 트러블슈팅** → 그래도 안 되면 각 페이지의 공식 문서 링크로 이동하세요.

## 학습 순서 제안

| 주차 | 학습 내용 | 페이지 |
|---|---|---|
| 1주차 | 환경 세팅 + AI 기초 개발 감 잡기 | 1 → 2 |
| 2주차 | Cursor × MCP 실전 (디자인 → 코드) | 3 |
| 3주차 | 실습 프로젝트 1개 선택·완주 | 4 → 4-1/4-2/4-3 |
| 4주차 | 나머지 프로젝트 + 나만의 서비스 응용 | 4-1/4-2/4-3 |

## 페이지 목차

- **1. 시작하기: 환경 세팅 체크리스트** — 계정 준비·설치·연결 확인
- **2. AI 기초 개발 학습 가이드** — 웹의 원리, Cursor 핵심 기능 4가지
- **3. Cursor × MCP 실전 가이드** — MCP 개념, Figma 디자인 → 코드 워크플로
- **4. 실습 로드맵** — 프로젝트 3종 허브
  - 4-1. 숙박 예약 스타일 웹 (데이터 수집)
  - 4-2. OTT 구독 스타일 웹 (결제)
  - 4-3. OTT 스타일 모바일 앱 (로그인)
- **5. 개념 사전** — 용어 30~40개 한 줄 풀이
- **6. 리소스 라이브러리** — 검증된 학습 자료 모음 (DB)
- **7. FAQ & 트러블슈팅**
