# 4. 실습 로드맵 (프로젝트 3종 허브)

> 배운 것을 진짜 서비스 형태로 완성해 보는 단계입니다. 세 프로젝트는 서로 독립적이니 **끌리는 것 하나를 골라 끝까지** 가는 것을 권합니다. 하나를 완주한 경험이 셋을 반쯤 아는 것보다 훨씬 값집니다.

## 프로젝트 고르는 법

| 프로젝트 | 이런 분께 | 새로 배우는 것 | 필요 계정 |
|---|---|---|---|
| **4-1. 숙박 예약 스타일 웹** | 데이터 다루는 서비스가 궁금하다 | n8n 자동화·웹 데이터 수집 | n8n (셀프호스트 무료) |
| **4-2. OTT 구독 스타일 웹** | 돈 받는 서비스를 만들고 싶다 | 결제위젯·구독(빌링) | 토스페이먼츠 개발자센터(무료) |
| **4-3. OTT 스타일 모바일 앱** | 앱을 만들어 보고 싶다 | React Native/Expo·로그인 | Supabase(무료) |

## 공통 진행 패턴

1. **디자인** — Figma에서 화면을 그리거나 커뮤니티 템플릿을 가져온다
2. **코드 생성** — Cursor Agent + Figma MCP로 화면을 코드로 만든다 (작은 컴포넌트 단위로!)
3. **기능 연결** — 프로젝트별 핵심 기능(수집/결제/로그인)을 공식 문서 경로로 붙인다
4. **확인** — 각 페이지의 체크리스트로 동작을 검증한다

> 💡 세 프로젝트 모두 "완성 화면 전체를 한 번에" 요청하면 실패 확률이 높습니다. 화면 하나 → 컴포넌트 하나 → 기능 하나 순서로 잘게 요청하는 것이 AI 협업의 핵심 기술입니다.
