# 2. AI 기초 개발 학습 가이드 (Part 1 대응)

> 코드를 한 줄도 몰라도 시작할 수 있습니다. 이 페이지는 "웹이 뭔지 감 잡기 → Cursor 핵심 기능 → 규칙 파일 → 첫 실습" 순서로, AI에게 개발을 시키는 기초 체력을 만듭니다. 목표는 코드를 쓰는 능력이 아니라, AI가 만든 결과물을 읽고 지시를 내리는 능력입니다.

---

## 1) 웹이 만들어지는 원리 — 30분 감 잡기

웹페이지는 딱 세 가지 재료로 만들어집니다. 집 짓기에 비유하면 이렇습니다.

| 재료 | 한 줄 풀이 | 집 비유 |
|---|---|---|
| HTML(웹페이지의 뼈대와 내용을 정의하는 언어) | 제목·문단·버튼이 "무엇이 있는지"를 정한다 | 골조와 방 배치 |
| CSS(생김새를 꾸미는 언어) | 색·크기·간격 등 "어떻게 보일지"를 정한다 | 벽지·조명·인테리어 |
| JavaScript(동작을 만드는 프로그래밍 언어, 줄여서 JS) | 클릭하면 반응하는 "움직임"을 만든다 | 스위치와 전기 배선 |

왜 알아야 할까요. AI가 코드를 다 써주더라도, 결과물을 보고 "버튼 색이 이상하면 CSS 문제, 클릭해도 반응이 없으면 JS 문제"라고 짚을 수 있어야 다음 지시를 정확하게 내릴 수 있기 때문입니다. 직접 코드를 쓸 필요는 없고, 이 구분이 되는 수준이면 충분합니다.

30분 코스 제안: 인프런 무료 강의 [웹개발 기초 HTML·CSS](https://www.inflearn.com/course/%EC%9B%B9%EA%B0%9C%EB%B0%9C-%EA%B8%B0%EC%B4%88-html-css)(총 2시간 34분, 11강)의 앞부분만 먼저 보세요. HTML과 CSS가 화면에서 각각 무엇을 담당하는지 눈으로 확인하는 게 목적이라, 전부 완주하지 않아도 됩니다. JS의 "동작" 개념은 노마드코더 무료 강의 [자바스크립트로 웹 서비스 만들기](https://nomadcoders.co/javascript-for-beginners)(60개 영상, 총 8시간)로 이어서 볼 수 있습니다. 단, 이 강의는 초급 이상의 HTML·CSS 이해를 선수지식으로 요구하니 순서를 지키는 편이 좋습니다.

## 2) Cursor 핵심 기능 4가지

Cursor(AI 비서가 내장된 코드 편집 프로그램)는 [cursor.com](https://cursor.com/docs/get-started/quickstart)에서 내려받아 설치하고, 무료 계정을 만들어 첫 실행 시 로그인하면 바로 쓸 수 있습니다. 요금은 Hobby 플랜이 신용카드 없이 무료이며, 한도는 "Limited"로만 표기되고 정확한 숫자는 공식 미공개입니다(2026-07 기준). 유료 Pro는 월 $20입니다(2026-07 기준). 학습 시작은 Hobby로 충분하고, 실습량이 늘어 한도에 걸리기 시작하면 그때 [공식 요금 페이지](https://cursor.com/pricing)를 보고 판단하면 됩니다.

핵심 기능은 네 가지입니다.

| 기능 | 무엇을 하나 | 비개발자 사용 시나리오 |
|---|---|---|
| Tab 자동완성 | 타이핑하는 동안 최근 편집·주변 코드·린터(코드 문법 검사기) 오류를 근거로 다음 코드를 제안 | 코드를 직접 칠 때만 유용. 초반에는 쓸 일이 거의 없으니 몰라도 된다 |
| Ctrl+K 인라인 편집 | 채팅창을 열지 않고, 선택한 코드 범위만 즉시 국소 수정 | 화면에서 고칠 부분을 드래그하고 "이 버튼 글자를 '문의하기'로 바꿔줘"처럼 짧게 지시 |
| Chat — Ask 모드 | 코드를 바꾸지 않는 읽기 전용 모드. 코드베이스를 이해·탐색하며 질문에 답한다 | "이 파일이 뭘 하는 건지 설명해줘" — 아무것도 망가뜨리지 않는 안전한 학습 모드 |
| Agent 모드 | 기능 제작·리팩터링(코드 정리)·버그 수정·테스트 작성·셸 명령(컴퓨터에 내리는 문자 명령) 실행까지 복잡한 작업을 독립적으로 수행 | "자기소개 페이지를 만들어줘" 한 문장으로 파일 생성부터 완성까지 맡긴다 |

비개발자에게 권하는 사용 순서는 이렇습니다. 먼저 Ask 모드로 물어보고(읽기 전용이라 안전), 만들 것은 Agent 모드에 통째로 시키고, 결과에서 마음에 안 드는 부분만 Ctrl+K로 콕 집어 다듬는 흐름입니다. Tab은 나중에 코드를 직접 만지게 될 때 자연스럽게 만나게 됩니다.

한국어 입문 자료로는 인프런 무료 연재형 강의 [WE CAN Cursor AI!](https://www.inflearn.com/en/course/we-can-cusor-ai)가 코딩 경험이 없는 입문자를 대상으로 하는 무료 강의라 이 단계에 잘 맞습니다.

## 3) 프롬프트로 개발한다는 것 — 규칙 파일이 왜 중요한가

프롬프트(AI에게 내리는 지시문)로 개발한다는 건, 매번 채팅으로 지시하는 것만을 뜻하지 않습니다. 매번 반복해야 하는 지시를 파일에 적어두면 AI가 항상 그것을 지키는데, Cursor에서는 이를 Rules라고 부릅니다.

- **Cursor Rules**: Agent에게 주는 시스템 수준 지시문입니다. 프롬프트·스크립트를 하나로 묶어 팀 전체가 같은 작업 방식을 공유할 수도 있습니다.
- **프로젝트 규칙(.cursor/rules)**: 프로젝트 폴더 안 `.cursor/rules` 경로에 `.mdc` 확장자 파일로 저장되며, 버전관리(파일 변경 이력을 기록하는 git) 대상이 됩니다.
- **AGENTS.md**: 프로젝트 루트(최상위 폴더)에 두는 순수 마크다운 파일로, `.cursor/rules`의 대안입니다.

참고로 옛 블로그에 자주 나오는 `.cursorrules` 단일 파일 방식은 현재 공식 문서에서 안내되지 않으며, `.cursor/rules`(.mdc)와 AGENTS.md 두 가지만 공식 형식입니다. 원문은 [Cursor Docs — Rules](https://cursor.com/docs/rules)에서 확인할 수 있습니다.

규칙 파일이 비개발자에게 오히려 더 중요한 이유는 명확합니다. 개발자는 AI가 이상한 코드를 내놓아도 눈으로 걸러내지만, 비개발자는 그 검수 능력이 없습니다. 그래서 "설명은 항상 한국어로 해줘", "내 확인 없이 파일을 삭제하지 마", "결과를 바꾸기 전에 무엇을 바꿀지 먼저 알려줘" 같은 문장을 규칙 파일에 넣어두는 것이 곧 안전장치가 됩니다. 말하지 않아도 지켜지는 가드레일을 미리 세워두는 셈입니다.

## 4) 첫 실습 — Agent 모드로 자기소개 웹페이지 1장 만들기

**[무엇을 배우나]** Agent에게 일을 시키고 → 결과를 확인하고 → 후속 지시로 다듬는 기본 사이클.

**[왜 필요한가]** 이후의 모든 실습(디자인 연동, 데이터베이스, 결제)이 전부 이 사이클의 반복이기 때문입니다. 가장 작은 결과물로 사이클 전체를 한 번 완주해 봅니다.

**[따라하기]**

1. 바탕화면에 새 폴더를 만들고 이름을 `my-intro`로 지정합니다.
2. Cursor를 실행하고 File > Open Folder로 그 폴더를 엽니다.
3. 채팅 패널을 열고 모드를 **Agent**로 선택합니다.
4. 다음 프롬프트를 입력합니다: "index.html 파일 하나로 된 자기소개 웹페이지를 만들어줘. 내 이름, 세 줄 소개, 좋아하는 것 목록을 넣고, 배경은 밝은 색으로, 휴대폰에서도 보기 좋게 만들어줘."
5. Agent가 파일을 만들면 내용 요약을 읽고 승인(Accept)합니다.
6. 폴더에 생긴 `index.html`을 더블클릭해 브라우저로 엽니다.
7. 후속 지시를 하나 해봅니다: "배경색을 연한 파란색으로 바꿔줘." 그리고 브라우저를 새로고침합니다.

**[✅ 이게 보이면 성공]**

- [ ] 브라우저에 내 이름이 들어간 페이지가 열린다
- [ ] 후속 지시(배경색 변경)가 새로고침 후 실제로 반영된다

**[막히면: 증상 → 해결]**

- 프롬프트를 보내도 아무 일이 없다 → 로그인이 됐는지, 폴더를 연 상태인지 확인합니다. Cursor는 계정 로그인이 필수입니다.
- 파일이 폴더에 안 보인다 → 채팅 안의 승인(Accept) 버튼을 눌렀는지 확인합니다. 승인 전에는 실제 파일로 저장되지 않습니다.
- AI가 자꾸 영어로 답한다 → 3번 섹션의 규칙 파일에 "항상 한국어로 답해줘"를 넣어 두세요.
